1103 ADS System v3.6.0 CHANGELOG
====================================

1. 盤面 UI / 操作性
- v3.5.2で試作したFIELD横長バーを正式採用。
- フィールド魔法は「小カード画像 + カード名 + カウンター数」で常時識別可能。
- 墓地 / 除外 / デッキ / EX は同じ1段内の小型チップとして維持し、主要10ゾーンの面積を確保。

2. フェイズ操作
- ドック展開時に DP / SP / M1 / BP / M2 / EP の6フェイズレールを追加。
- 現在フェイズを強調表示。
- DUELモードでは、エンジン上合法な遷移先だけ操作可能。
- 従来の大きな「次へ」ボタンとスワイプ操作は維持。

3. 現在有効な制約の可視化
- temporaryFlags.noSpecialSummon -> 「特殊召喚禁止」
- temporaryFlags.noBattlePhase -> 「BP不可」
- 攻撃モンスター制限 -> 「攻撃モンスター制限」
- 制約が存在する時だけプレイヤー盤面に小型バッジを表示。

4. チェーン表示 / 安全性
- 常時チェーンリボンを CL番号 / カード名 / P1-P2 / Spell Speed で表示。
- 無効化されたリンクを視覚的に区別。
- DUELモードではリボンから直接 resolveChainStep() を呼ばず、優先権確認へ戻す。
  これにより応答権を飛ばしてチェーンを解決する誤操作を防止。

5. 墓地 / 除外 / デッキ / EX の操作性
- 文字ボタン一覧から、カード画像付きリストへ変更。
- 墓地・除外は最新カードを上に表示。
- デッキはTOPを上に表示。
- 効果発動可能カードに「⚡効果」、明示スクリプト対応カードに「AUTO」表示。

6. カードスクリプト改善（240種類を維持）
- ブラック・ローズ・ドラゴン
  ①S召喚時の全体破壊に加え、②墓地の植物族除外 -> 相手守備表示を表側攻撃表示 -> ATK0（ターン終了時まで）を自動化。
- 粋カエル
  墓地自己特殊召喚に加え、「S素材にできない」をEX素材候補エンジンで強制。
- XX－セイバー ヒュンレイ
  S召喚時の魔法・罠破壊を、従来1枚のみから「3枚まで選択」へ拡張。

7. 開発構成
- Acode版: carddata.json 4,996枚を内蔵した単一HTML。
- 開発版: engine / cards / ui / runtime / data を分割した構成を維持。
- 明示スクリプト: 240 unique / 240 total。
