## 3. 実経路で測ったこと

`tools/test_s03_u533_blood_ogre.js`（17 PASS）。Replay 監査は 6 場面。

- A1: 登録、手札のクイックエフェクト、数値の誘発、攻撃対象の制限、ゾーン限定の印。
- B1: 相手の 2 回目の直接攻撃宣言時に手札から特殊召喚し、攻守が 1 回目の《デーモンの召喚》と同じ
  2500 / 1200 になる。
- C1: negative control。3 回目の直接攻撃宣言時には発動できない。
- D1: 1 回目の直接攻撃を《魔法の筒》で無効にすると記録が 0 件になり、次の宣言が「1回目」、その次が
  「2回目」として発動できる。
- E1: 1 回目のモンスターを《月の書》で裏側守備表示にした場合、数値は 0 のまま。
- F1: 特殊召喚後に《リビングデッドの呼び声》で出した自分のモンスターは攻撃対象に選択できず
  （「「血涙のオーガ」の効果で「ワイト」は攻撃対象に選択できません」）、このカード自身は選択できる。
- G1: 《バトルフェーダー》を同一チェーンで発動した場合、このカードは発動できない。
- H: 当時裁定の ID、共通側の説明、報告書、`tools/check.py` への登録。

関連テストも通過: `test_battle_v6`・u39・u49（バトルフェーダー）・u149・u150・u152・u160・u218・u251・u530・
`test_expansion_v350`。
