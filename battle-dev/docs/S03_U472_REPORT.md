## 設計（実装したもの）
**複数かどうかは、効果自身の宣言で決める。現在の選択の形から推測しない。**
1. `engine/1ZZR_target_source_s03.js`: スクリプトの `targetCount: N`（1以上の整数）を、正規化済みの `effectInfo` に `targetCount`（宣言した数、無ければ `null`）と `targetsMultiple`（`targetCount >= 2`）として出す。ソースは `ACTIVATION_PREP_S03` / `RESOLVING_LINK_S03` / `P3_EFFECT_CONTEXT` / `ACTIVE_SCRIPT` から既に引いている名前（`CARD_SCRIPTS[name]`）。明示の effectInfo が `targetCount` を持てばそれを優先。純粋な読み取りで、保存する状態は無い（Save / Replay に何も足していない）。数えるのは**効果の対象だけ**（コストの選択は数えない）。
2. `cards/C5_auto_cycle23.js`: メタルシルバー・アーマーの `immuneToTarget` / `immuneToTargetOffField` だけが `d2ArmorExemptMultiTarget(effectInfo)`（`Number(effectInfo.targetCount) >= 2`）を読み、その時は制限を掛けない。**唯一の消費者**（テストで固定: 対象耐性フックの本文が宣言を読むスクリプトは、丁度メタルシルバー・アーマーだけ）。
3. 宣言を置いたのは5枚だけ（テストで固定: `targetCount` を持つスクリプトは丁度この5枚）。強制脱出装置・因果切断・デュアルスパーク等は宣言なし = 単体。
4. 制約: スクリプト単位の宣言なので、複数対象の効果と単体対象の効果を併せ持つスクリプトには使えない（効果ごとの宣言が要る）。現時点で該当カードなし。

### なぜ選択の min/max から推測しないか
5枚の対象選択は全部「1枚ずつ min 1 / max 1 の選択を繰り返す」形で開く（貪欲な壺は5回）。この形は 強制脱出装置（対象1体）の選択と**同じ**。形で分類すると、貪欲な壺は単体扱い、または強制脱出装置が複数扱いになる。テストで固定:
- 貪欲な壺の5回の選択はどれも min 1 / max 1、かつどの時点でも `targetCount` 5。強制脱出装置の1回の選択も min 1 / max 1 だが `targetCount` は null（制限されたまま）。
- 貪欲な壺から `targetCount` だけを外すと、選択の形は変わらないのにアーマーの制限が戻り、対象選択が候補不足で失敗して準備が U471 のトランザクションで元に戻る。
- 直接 `requestChoice` に min 2 / max 2 の「複数ピック」を出しても、宣言が無い単体スクリプトの名前では制限され（2枚選べない）、宣言のある貪欲な壺の名前では全モンスターが候補に出る。

## コストは数えない（証明）
- ゴッドバードアタック: 実際の発動で選択は**3回**（リリース = コスト、対象1/2、対象2/2）開くが、3回とも `targetCount` は **2**。チェーンリンクが持つ対象は2つ（3つではない）。コストの鳥獣族（アーマーに守られている相手側の自分のモンスター）は候補に出る。
- 反事実（分類が数え方で変わる実例）: 因果切断（手札を1枚捨てる = コスト、相手の表側モンスター1体を対象 = 計2回の選択）は宣言なし = 単体で、アーマーの下では装備モンスターだけが候補。同じスクリプトを一時的に `targetCount:2`（コストも数えた宣言）にすると、保護されたライオウ・ワイトまで候補に入る。テストはこれを実行し、戻して制限が復活することを確かめる。

## 実際に通した検証（5枚それぞれ: 発動 → 対象選択 → チェーン → 解決 → Replay）
盤面: P0 = アーマー（サイバー・ドラゴンに装備）のコントローラー（ライオウ・ワイトも場）、P1 = 発動する側（アーマーの「相手」）。
- **貪欲な壺**: 墓地のモンスター6体のうち保護された5体を1枚ずつ選び（候補 6,5,4,3,2）、5体がデッキに戻り2ドロー（デッキ 12+5−2=15）、残る1体は墓地。
- **諸刃の活人剣術**: 墓地の六武衆3体から2体（候補 3,2）、2体が攻撃表示で特殊召喚、エンドフェイズの破壊＋ダメージ予約が登録。
- **毒蛇の供物**: 自分の爬虫類族（保護）→ 相手のカード（候補にライオウ・ワイト・サイバー・ドラゴン・アーマー）2枚。3枚が破壊、装備モンスターとアーマーは残る。
- **TGX3－DX2**: 墓地の「TG」3体（候補 3,2,1）、墓地を離れて2ドロー（デッキ 12+3−2=13）。
- **ゴッドバードアタック**: コストの鳥獣族 → 場の保護されたライオウ・ワイトを対象、破壊。
- 各カードで: 準備が中止されない（`PREP_TX_ABORT` なし、「選択できるカードが足りません」なし）／チェーンリンクが宣言どおりの数の対象を持つ／解決結果／**Replay 監査**（全ダイジェストと最終状態が一致）／アーマー無しの対照（貪欲な壺）と同じ形・同じ結果。
- **Save/Load**（2VM）: 5枚とも、チェーンリンクが載った状態（保護されたカードを含む対象を持つ）を保存 → 読込 → 状態ダイジェスト一致・リンクの対象数一致 → 優先権を渡して解決 → 途切れなく進めた対局と**全追跡カードの位置・デッキ手札の枚数・最終ダイジェストが一致**、読込後の Replay 監査。
- **対照**: 強制脱出装置（単体）はアーマーの下で候補が装備モンスターだけ（4体の場で1体）、装備モンスターは手札に戻る。アーマー無しなら4体とも候補。リビングデッドの呼び声（単体・墓地）は引き続き発動前に断られる（U468/U470）。
- **他の耐性は変えない**: ゴッドバードアタックをアーマー有り／無しで。ホルスのしもべが守る「ホルスの黒炎竜」とオベリスクの巨神兵（自身のテキスト）は、複数対象でも候補に出ない（アーマー有りでも）。毒蛇の供物でも同様。オベリスク2体だけの場でのゴッドバードアタックは候補不足になり、**U471 のトランザクションがリリースを戻す**（U470 が記録した「リリースした鳥獣族が戻らない」状態の、アーマー以外の耐性による版が閉じている）。
