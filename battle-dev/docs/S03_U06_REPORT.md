Base: `checkpoint_claude_s03_u05_lock_recovery_b_20260911.zip`, SHA256 `88160ac76191844c76e5f7af37b8b428a3845d230a6e717843ec2e300df64f71`.

## Requirement closure record

- **Requirement** (user, 2026-09-11)
  - For normal play, 兎ラギア is the opponent's sample deck. Player 1 keeps the deck the user loaded; only Player 2 gets `RABBIT_LAGGIA_DECK`.
  - Both players shuffle and draw 5 in a fresh duel.
  - If Player 1 has no loaded deck, nothing starts and the user is asked to load one.
  - The developer both-sides 兎ラギア start, fixed openings and regression tests stay separate.
  - The labels must make the meaning clear.
- **Root cause:** INTEGRATION_MISSING.
  - Every normal-play entry point called the developer start `startTestDuel(true,0,'rabbit')`, which overwrote Player 1.
  - The loaded deck list was not recorded anywhere, so a fresh duel could not be rebuilt from it once cards had moved.
- **Closure**
  - `LOAD_DECK` now records `P.loadedDeckV32` with the source (`user` / `test` / `opponentSample`), the deck name, and the main and EX card IDs. This state is JSON-safe and journaled.
  - `applyLoad` and `loadSaved` mark decks as `user`. Developer and preset starts mark them as `test`.
  - New `startRabbitOpponentDuel()` builds a fresh duel from Player 1's stored user list and the 兎ラギア sample.
  - Normal UI entry points now call it:
    - the hand-empty button 「兎ラギアと対戦開始」;
    - the menu entry 「⚡ 兎ラギアと対戦開始」;
    - the deck-list row 「1103兎ラギア（対戦相手用）」 with the badge 「対戦相手」.
  - The developer menu gains a separate row 「両側1103兎ラギア」 that calls the unchanged `startTestDuel`.
- **Consumers:** normal play (home and hand-empty button, menu, deck list), the developer preset menu, and the SaveLoad resume of a loaded user deck.
- **Recovery:** no card status change (UI unit).
- **Remaining:** none for this request. The Player 1 deck is not validated as a legal 40–60 deck; any user-loaded deck with main cards is accepted, as before.
- **Practical effect**
  - A user can load their own deck and play against the sample 兎ラギア with one click, and rematch.
  - The developer both-sides test is still available.
