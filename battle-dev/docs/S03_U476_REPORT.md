### ユーザーが「偽陽性」とした項目の検証
- サイバー・ヴァリー: v4 で既に `targets:true`（モード選択は対象の選択ではない）。**偽陽性で正しい**（A に入らない）。
- ツタン仮面・フォースフィールド: 選択を開く経路に到達しない（A〜D のいずれにも入らない）。**偽陽性で正しい**。
- コアキメイル・クルセイダー: 「手札の獣戦士族1体を相手に見せる」は公開・コスト（正しい）。ただし同カードの 2 つ目の効果「墓地の『コアキメイル』1体を選択して手札に加える」は**解決時**の選択で C の道に入る（A ではない）。
- RAI－JIN: 「光属性モンスター1体を選択して破壊する」は強制誘発の効果の節であり、継続効果の節ではない。実装は**解決時**の選択（C の道、`targets:false` と明示）。A ではない。
- D・ステープラン: 上記のとおり**偽陽性ではなく本当の対象**（修正済み）。

## 欠陥
`API.selectCard` は対象耐性の要否（`targeting`）を「スクリプトの `targets:true`」から導く（`engine/40_legal_script_engine.js:1315`）。宣言が無いと `targeting=false` で `filterTargetable` が一度も掛からず、さらに `engine/1R` の `linkTargetUidsS03`（解決時の発生源 `srcS03.tg`、「対象を取らない効果では破壊されない」の判定）も `targets:true` の時にしか対象を載せない。基点での実測（8 枚）:
- 6 枚（スノーマンイーター / ヒュペリオン / バイサー・デス / ステープラン / カラクリ参謀 / カラクリ忍者）: 対象の選択は `targeting:false`。**オベリスクの巨神兵が候補に出る**。スノーマンイーターとバイサー・デスで、候補がオベリスクだけでも発動が通り、スノーマンイーターは**オベリスクを破壊した**（基点の実測: オベリスクが `1:grave`）。メタルシルバー・アーマーの下でもカラクリ忍者は墓地の「カラクリ」を選んで特殊召喚できた。
- ゴルド／グラファは選択側が `targeting:true` を明示していたので耐性は効いていたが、`linkTargetUidsS03` が空・`srcS03.tg` 無し。
