# S03-U513 任意の装備身代わりと、それを使う 3 枚のカード実装

カード実装率の方針（優先度2）の 2 件目。

## 実装した範囲

| カード | 区分（前）| 実装した効果 |
|---|---|---|
| 《ファイティング・スピリッツ》 | NOT_STARTED | 装備モンスターの攻撃力＋300×相手フィールドのモンスター数 ／ 装備モンスターが**戦闘**で破壊される場合、代わりにこのカードを破壊**できる** |
| 《白銀の翼》 | NOT_STARTED | レベル8以上のドラゴン族シンクロにのみ装備可能 ／ 装備モンスターは**1ターンに2度まで**戦闘では破壊されない ／ 装備モンスターが**カードの効果**で破壊される場合、代わりにこのカードを破壊**できる** |
| 《大和神》 | ENGINE_GAP | 通常召喚できない ／ 自分の墓地のスピリット1体を除外して手札から特殊召喚 ／ 特殊召喚したターンのエンドフェイズに持ち主の手札へ戻る ／ 戦闘で相手モンスターを破壊した場合、相手の魔法・罠1枚を破壊**できる** |

## 足した共通処理（最小限）

装備カードが `equipSubstituteOptionalS03:{causes:[...]}` を申告すると、S03-U173 の**任意の破壊身代わり**
（`engine/1ZV`）に種別 `'equipSub'` の選択肢として出る。申告するのは**装備カードの側**で、
守られるのは**装備モンスター**なので、`destroySubDeclS03` はモンスターに付いている装備カードを見る。

- 原因（`'battle'` / `'effect'`）で絞る。《ファイティング・スピリッツ》は戦闘だけ、《白銀の翼》は効果だけ。
- 表側表示で、効果が無効にされていない装備カードだけが候補になる。
- 選択肢は「代わりに装備カード「X」を破壊する」と、既存の「使わずに破壊する」。
- **強制版**（S03-U183 の `equipSubstituteS03`、破壊の reducer 側）には**手を付けていない**。

これを必要とするカードは他にもある（《ヴィシャス・クロー》＝手札に戻す・《鋼核収納》＝墓地へ送る）が、
行き先が違うので今回は入れていない（下記 未対応）。

## 《大和神》の ENGINE_GAP の記録は失効していた

記録は「『このカードは通常召喚する事ができない』の消費側が無い（`cannotSpecialSummon` は逆向きだけ）」
だったが、実測すると `cannotNormalSummonS03`（`engine/70`・S03-U190）が存在し、
スクリプトの `cannotNormalSummon:true` を読んでいた。また `FX_SPECIAL_SUMMON` が `summonedTurn` を
立てるので（`engine/00`）、S03-U244 のスピリットの戻り（`spiritActiveTurnS03`）がそのまま効く。
分類を緩めたのではなく、記録された根拠が消滅していた。

## 実測（実経路）

フェイズ移行は `PROCESSOR_V27.PHASE`、攻撃は `PROCESSOR_V27.ATTACK`。

- ファイティング・スピリッツ: 相手モンスター2体で攻撃力 +600。《デーモンの召喚》の攻撃で
  「代わりに装備カードを破壊」を選ぶとモンスターが残り、「使わずに破壊する」を選ぶとモンスターが破壊される。
  **効果破壊（《地砕き》）では身代わりの選択が出ない**（申告は戦闘だけ）。
- 白銀の翼: 《スターダスト・ドラゴン》（星8・ドラゴン・シンクロ）に装備でき、ワイトには装備できない。
  《青眼の白龍》の攻撃を 2 度までは耐え、3 度目で破壊される（LP は 500×3 減る）。
  《地砕き》の効果破壊では代わりに装備カードが破壊される。
- 大和神: `cannotNormalSummonS03` が真。墓地の《八汰烏》を除外して手札から特殊召喚でき、
  墓地にスピリットがいなければ特殊召喚できない。特殊召喚したターンのエンドフェイズに手札へ戻る（強制）。
  戦闘で《ワイト》を破壊した場面では相手のセット《サイクロン》を破壊でき、
  自分が《青眼の白龍》に戦闘破壊された場面では発動しない。
- negative control: 強制版の《八汰鏡》は選択を出さずに今までどおり身代わりになる。
- 各場面で Replay 監査（全 Action の digest と最終状態）を取っている。

## 未対応の範囲

1. **行き先が「破壊」以外の装備身代わりは入れていない。**
   《ヴィシャス・クロー》（「代わりにこのカードを**手札に戻す**」・強制・戦闘）と
   《鋼核収納》（「代わりにこのカードを**墓地へ送る**事ができる」・任意・エンドフェイズの自壊）は、
   同じ枠に行き先の種類を足せば入るが、この単位では触っていない。
2. 《白銀の翼》の「1ターンに2度まで」は v21 の `perTurn:2` で入れた。
   当時裁定で「2 度まで」の数え方（装備し直した場合など）がどうなるかは**確認していない**。
3. 《大和神》の②は任意誘発として入れた（「破壊する事ができる」）。
   同時に複数の戦闘が起きる場面での処理順は**確認していない**。
4. スピリット関連で残っている未実装: 《リチュア・エミリア》（「リチュア」の原型判定が
   `data/setcode_overlay_v4.json` に無く、カード名の部分一致は禁止）・《ドラゴン・ウォリアー》（融合）。

C 白銀の翼 7・D 大和神 8・E negative control 2・G 文書と登録 2。うち 9 場面で Replay 監査）。

**測り方の注意**（この単位で踏んだ）: `PROCESSOR_V27.TURN` は**エンドフェイズから**でないとターンが
変わらない（「DUELモードではエンドフェイズからターンを終了してください」）。`phase('end')` を先に
通さずに `turn()` を呼ぶと、相手の攻撃を自分のターン中に行う不自然な経路になる。6 箇所を直した。
また、相手の手札などの盤面は `baselineA()` の**前**に置かないと Replay 監査が合わない。
