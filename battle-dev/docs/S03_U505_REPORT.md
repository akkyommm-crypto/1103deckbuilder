## 2. いまの句抽出では読めない（実測。これが実装前の障害）

(B-2) の正規表現は `(?:に成功した|された|した)(時|場合)` で、句の直前に並ぶ**召喚語**だけを読む。

- 「破壊された時」… 「された時」には当たるが、直前の「破壊」が召喚語の表に無いので句として捨てられる。
- **「墓地へ送られた時」… 正規表現そのものが当たらない**（「送られた」は「された」でも「した」でもない）。
  そのため `onSendToGrave` の 180 枚は 1 枚も分類できない。
  実測でも、テキストに「墓地へ送られた時」を含む候補はすべて句 0 件になる。

## 5. 次の単位で入れる形（設計書 (F)）

1. (B-2) の正規表現に「られた」を足し、語の表に破壊・墓地送り・除外・リリースを足す。
   **召喚語の読み方は変えない**（R9 の区別を壊さない）。
2. (B-3) に種別 `destroyed`（D / B）と `sentToGrave`（G / GF）を足す。既定は**無効**にし、
   (B-5) の許可リストに入った（カード, イベント, 効果）だけを落とす。
3. (B-5) に「逃す」12 枚をカードごとに裁定 ID 付きで入れる。「逃さない」12 枚は (B-1) の `never` 宣言へ。
   《黒衣の大賢者》は R6 として落とさない。
4. `onLeaveField` は**種別に入れない**。S03-U501 / U502 で見たとおり、これは盤面の差分から検出される
   ルール処理で、破壊とは別の軸である。
5. **1 単位で全部は入れない。** まず破壊（D）の分だけ入れ、墓地送り（G、112 枚の「時」）は別単位にする。
