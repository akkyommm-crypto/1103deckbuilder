# S03-U530 — 《テュアラティン》

カード実装の計画の 19 単位目。「バトルフェイズ開始時の状態」を engine が残していなかったので、
それだけを共通側に足した（Action の中で取るので Replay・保存・再開でも同じ値になる）。

| カード | 種別 | これまで | この単位 |
|---|---|---|---|
| テュアラティン | 効果モンスター（星8・天使・光・2800/2500） | NOT_STARTED | TESTED |

## 1. 共通側に足したもの（最小限）

`engine/00_state_actions.js` の `SET_PHASE`（Action）で、バトルフェイズに入る時に
`gs.bpStartS03 = {turn, player, mz:[[uid…],[uid…]], hand:[[uid…],[uid…]]}` を取る。
「バトルフェイズ開始時に自分フィールド上にモンスターが2体以上存在し」と
「バトルフェイズ開始時に手札に存在しない場合は特殊召喚できない」（WIKI-ED7E3C19B11C 09/12/13）の
どちらも開始時の状態が必要で、engine はそれを残していなかった。

「戦闘によって破壊され墓地へ送られた」の判定には既存の破壊の記録
（`gs.destroyedThisTurnV30` の `battle:true`、engine/1M）を使う。
`battleKillsS03` は「破壊した側」の記録なので使わない。

## 2. 当時裁定から組み立てたもの（推測していない）

- `WIKI-6262167F5175` / `WIKI-4CDE65C5B0A5` 最後の 1 体が破壊された時に特殊召喚できる
  → 戦闘破壊のイベント（`onBattleDestroy`）で、開始時の全員が墓地にあるかを見る。
- `WIKI-323A76C20CAD` 戦闘以外で墓地へ行ったモンスターが 1 体でもいたら特殊召喚できない
  → 開始時の uid すべてについて「破壊の記録が battle:true」かつ「今、墓地にある」事を要求する。
- `WIKI-ED7E3C19B11C`（09/12/13）バトルフェイズ開始時に手札に無ければ、その後に加わっても特殊召喚できない
  → 開始時の手札の記録を見る（《強欲な瓶》で引いて実測）。
- `WIKI-11583ED612D9` 宣言した属性にこのカード自身が含まれる場合、自分も破壊される
  → 宣言の後に「フィールドの表側表示でその属性のモンスター」を全て破壊する（自分も対象に含まれる）。
- `WIKI-F2CBC0269F5E`（08/12/26）神属性も宣言できる → 宣言の候補に神を入れる。
- `WIKI-4DCA769F6F52`（10/05/07）封印はその時のコントローラーから見た「相手」に適用される
  → `summonLockS03` で `i.p !== i.srcPlayer` の時だけ止める（コントロールが移れば止める相手も変わる）。
- `WIKI-51F3EEE1E826` 同時に誘発する他の効果とは好きな順番でチェーンを組める
  → 通常の誘発として積む（engine の SEGOC のまま）。

## 3. 実経路で測ったこと

`tools/test_s03_u530_tualatin.js`（16 PASS）。Replay 監査は 6 場面。

- A1: 登録、2 つの効果、召喚封印の申告、ゾーン限定の印の登録。
- B1: 相手のバトルフェイズで開始時の 2 体が順に戦闘破壊され、2 体目の後に手札から特殊召喚
  → 闇属性を宣言して相手の《デーモンの召喚》2 体を破壊（自身は光属性なので残る）。
- C1: 光属性を宣言すると相手の《シャインエンジェル》とともに自身も破壊される。
- D1: 宣言された闇属性は相手が召喚できず（`v46FaceUpSummonRestrictionReason` が理由を返す）、
  光属性は召喚できる。
- E1: negative control。開始時のモンスターが 1 体だけなら特殊召喚できない。
- E2: negative control。1 体が《地砕き》で墓地へ行っていた場合は特殊召喚できない。
- E3: negative control。開始時に手札に無く《強欲な瓶》で引いた場合は特殊召喚できない。
- F: 当時裁定の ID、報告書、`tools/check.py` への登録。

関連テストも通過: 召喚封印（u384 / u398 / u415 / u429）・`test_battle_v6`・`test_provenance_v30`・
u251・u308・`test_codex_c10_phase_priority`・u152（バトルフェイズ終了時）。

## 4. 未対応・後続課題

1. 封印の属性判定は `summonLockS03` に渡る DB の属性（`i.db.at`）で見ている。複数属性を持つカード
   （《ダーク・シムルグ》など）や属性を変える効果が絡む場合は一致しない可能性がある（**未対応**）。
   共通の `summonLockReasonS03` が DB の属性しか渡さないため、直すには共通側の引数を増やす必要がある。
2. `WIKI-51F3EEE1E826`（《シャインエンジェル》と同時に誘発した場合に好きな順番でチェーンを組める）は
   **未測定**。
3. `WIKI-F56FBA56619D`（1 体目と 2 体目の戦闘破壊の間に《強欲な瓶》を発動した場合の扱い）は、
   E3 で「開始時に手札に無ければ出せない」側だけを測った。瓶そのものの扱いは**未測定**。
4. このカードは「相手のバトルフェイズ時に発動する」と書かれているので、自分のバトルフェイズでは
   発動できない実装にしている（engine の `activePlayer` で判定）。自分のバトルフェイズでの扱いを
   明示した当時裁定は見つからなかったので、テキストどおりにした（**未確定**）。
5. S03-U517〜U529 から持ち越しの項目は各報告書のとおり。

イベントごとの組 678 → 679（組の強制 319 → 320）。
