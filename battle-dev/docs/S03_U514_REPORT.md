# S03-U514 エクシーズ素材を使う 3 枚のカード実装

カード実装率の方針（優先度2）の 3 件目。**新しい共通処理は足していない**（既存の仕組みだけで足りた）。

## 実装した範囲

| カード | 区分（前）| 実装した効果 |
|---|---|---|
| 《巨星のミラ》 | NOT_STARTED | 破壊される場合、代わりにエクシーズ素材を1つ取り除ける ／ 自分フィールドの表側表示のレベル4以下のモンスターはカードの効果では破壊されない |
| 《ブラック・レイ・ランサー》 | NOT_STARTED | 1ターンに1度、素材を1つ取り除き、フィールドの表側表示モンスター1体の効果をそのターンの終わりまで無効にする |
| 《ラヴァルバル・イグニス》 | NOT_STARTED | このカードが戦闘を行うダメージステップに1度だけ、素材を1つ取り除いて攻撃力をエンドフェイズ時まで500アップ |

## 使った既存の仕組み

- 任意の破壊身代わり（S03-U173、`engine/1ZV`）の種別 `'detach'` …… 《巨星のミラ》①
- 破壊耐性（v21、`engine/1K`）の `continuous.protectV21`（`effect` 側・`scope:'ownMonsters'`）…… ②
- X素材のコスト（S03-U114、`engine/1ZF`）の `detachCostS03` …… ランサー・イグニス
- `card.negatedUntilTurn`（《エフェクト・ヴェーラー》と同じ記録）…… ランサー
- ダメージステップの発動（`dsTiming`）と `API.modAtk(..., 'endPhase')` …… イグニス

**測り方で踏んだ点**: `detachCostS03` を宣言したカードは P1.1 の準備付き発動を通るので、
対象の選択は `detachCostS03.targets` にも宣言しないと走らない（`selectTargets` だけでは
素材を払う経路で対象が選ばれない）。《No.11 ビッグ・アイ》と同じ形に揃えた。

## 実測（実経路）

- 巨星のミラ: 《ブラック・ホール》に対して素材 3→2 で場に残る。素材 0 なら破壊される。
  自分のレベル1は守られ、自分のレベル6と相手のレベル1は破壊される。
- ブラック・レイ・ランサー: 素材 2→1 で相手《人造人間－サイコ・ショッカー》が
  `effectNegated` になり、`negatedUntilTurn` が現在のターン。素材 0 では発動できない。
  同じターンの 2 度目は発動できない（素材は残っている）。
- ラヴァルバル・イグニス: 《デーモンの召喚》(2500) との戦闘で素材1つを取り除き、
  攻撃力 1800→2300 になるので戦闘ダメージが 700 ではなく **200**。素材 0 なら 700 のまま。
  同じダメージステップでは素材が 1 つしか減らない。
- 上記の各場面で Replay 監査（全 Action の digest と最終状態）を取っている。

## 未対応の範囲

1. **「1 度だけ」の数え方は近似**。同じダメージステップでの重複発動は
   「ターン＋攻撃モンスターの uid＋その攻撃回数」で区別している。
   当時裁定で「ダメージステップ時に1度だけ」がどの単位か（1 回の戦闘か、1 ダメージステップか）は
   **確認していない**。同じ 2 体が同一ターンに 2 回戦闘する場合は別の戦闘として扱う。
2. 《ブラック・レイ・ランサー》の「エンドフェイズ時まで無効」は、《エフェクト・ヴェーラー》と同じ
   「そのターンの終わりまで」の記録で表している。エンドフェイズ中の細かい前後関係は**未確認**。
3. エクシーズ素材の族で残っている未実装: 《No.83 ギャラクシー・クィーン》
   （「次の相手のエンドフェイズ時まで」自分のモンスター全体に戦闘耐性と貫通を与える継続的な付与が要る）と
   《エクシーズ・ギフト》（素材 2 つを**複数のエクシーズモンスターに跨って**選ぶ必要があり、
   いまの `detachCostS03` は 1 体からまとめて払う形）。どちらも別単位。
