# S03-U508 《歯車街》②を「破壊され墓地へ送られた時」の誘発に直した

## 何を直したか

《歯車街》②のテキストは

> ②:このカードが破壊され墓地へ送られた**時**に発動できる。
> 自分の手札・デッキ・墓地から「アンティーク・ギア」モンスター1体を選んで特殊召喚する。

で、**任意の誘発効果**である。この単位の前のスクリプトは `activateFrom:["grave"]` と
「墓地にあること」だけが条件で、**破壊と無関係にいつでも墓地から発動できた**。

実測（この単位の前）:

```
strictScriptLegalityV2('歯車街',0,'grave',0,{})  →  {ok:true}      ← 破壊が一切起きていない状態
フィールドの《歯車街》を《サイクロン》で破壊     →  候補 0 件（誘発として拾われない）
```

ほかの墓地誘発（《ダンディライオン》《TG ジェット・ファルコン》）と同じ作法に揃えた:

- `passive:{ onSendToGrave(ctx){ … } }` を足して、自分が墓地へ送られたイベントで拾う。
- `condition` で `ctx.eventName === 'onSendToGrave'` と `eventIsSelfS03(ctx)` と
  `gearTownDestroyedS03(ctx)`（`graveInfo.byDestroy`）を確認する。
- **破壊された場所は条件に入れない。** 当時裁定 `WIKI-CA554A0F5EEB`（**回答日 2008-04-21**、
  掲載ページ《歯車街》）が「手札やデッキからの破壊でも発動可能です。(08/04/21)」と答えている。

これが誘発効果（そのタイミングでチェーンブロックを作る発動）であることは
`WIKI-5818C64C44A1`（**回答日 2009-01-09**）「破壊され墓地に送られた時の《歯車街》の効果を
無効にすることはできますか？」→「はい、無効にできます。(09/01/09)」でも裏付けられる。

実経路で測って当時裁定と一致したもの。

| 場面 | 当時裁定 | 回答日 | 結果 |

| 《デュアルスパーク》で破壊 → ドロー | `WIKI-590A1789DD22` | **2009-09-12** | 発動できる（破壊とドローは同時）|

## 未対応の範囲

1. **《グリフォンの羽根帚》の場面で、当時は逃すのにいまは発動できてしまう。**
   `WIKI-1B4D52FCA757`（**回答日 2010-08-11**）「破壊後に回復の処理が挟まるので、タイミングを逃します。」
   一般則も同じ向きで `WIKI-378544C74049`（**回答日 2008-05-30**、《砂塵の大竜巻》）
   「破壊が条件の任意効果はタイミングを逃すことになります。」

   **なぜこの単位で直さなかったか（実測）**: 墓地送り（G）の種別を (B-3) に開けて (B-5) の許可リストに
   《歯車街》を入れれば R4（刻みと現在値の比較）が当たるが、**同時として扱う処理が刻みを進める**ため、
   回答日つきの裁定 2 件が壊れる。

   | 場面 | 当時裁定 | 《歯車街》の刻み → 解決の終わり | R4 を当てると |
   |---|---|---|---|
   | 《サイクロン》| （破壊だけ）| 2 → 2 | 落とさない（正しい）|
   | 《燃えさかる大地》| **09/03/02** 逃さない | 2 → 2 | 落とさない（正しい）|
   | 《グリフォンの羽根帚》| **10/08/11** 逃す | 2 → 3 | 落とす（正しい）|
   | 《光帝クライス》| **09/01/28** 逃さない | 3 → 6 | **落とす（誤り）** |
   | 《デュアルスパーク》| **09/09/12** 逃さない | 3 → 4 | **落とす（誤り）** |
   | 《大嵐》| 裁定**未確認** | 2 → 3 | 落とす |

   直すには (A) の刻み方そのもの（1 回の解決の中で同時として扱う処理を 1 つの刻みにまとめる）を
   変える必要がある。**別単位**。実際に入れてみて測った結果も残してある（入れると
   《大嵐》《デュアルスパーク》の 2 場面で `MISSED_TIMING_DROPS_S03` に《歯車街》が載った）。

2. **フィールド魔法の張り替えが未実装で、`R1103-GEAR-001` / `-002` / `-003`（いずれも**回答日なし**）の
   場面を測れない。** フィールドゾーンが埋まっている状態で別のフィールド魔法を発動すると
   「フィールドゾーンが埋まっています」で止まる（実測）。張り替えは《歯車街》の主要な誘発経路なので、
   カード側だけ直してもこの入口は開いていない。

3. **《大嵐》の同時破壊についての当時裁定を見つけていない。** テストでは「発動できる」という
   いまの挙動と、墓地送りの Action が 1 枚ずつ刻みを進めることだけを記録している。

4. **《古代の機械巨人》《古代の機械獣》の `carddata.json` のテキストに「このカードは特殊召喚できない。」が
   入っている（未確認）。** そのため《歯車街》で《古代の機械巨人》を特殊召喚できない（実測で
   `API.specialSummon` が `false` を返す）。1103 当時のテキストがどうだったかは**調べていない**ので、
   この単位では何も変えていない（テストでは《古代の機械兵士》を使った）。S03-U494 の時代混在の軸。

5. タイミングを逃す仕組み全体の公開範囲は **(B-5) 45 枚 / 66 組＋宣言 8 件**のまま。この単位では
   1 件も増やしていない。**全カード・全タイミング規則が完成したわけではない。**
