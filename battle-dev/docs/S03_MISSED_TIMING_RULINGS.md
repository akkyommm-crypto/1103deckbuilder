# 「タイミングを逃す」に言及する当時裁定（抽出）

S03-U490 で、保存済み裁定 DB（`1103_rulings_complete_v8_154.zip` → 10,870 件、2011-08-31 以前）から
「タイミングを逃」を含む **123 件**を機械抽出し、回答文のパターンで粗く分類したもの。
分類（`does-not-miss` / `misses` / `unclear`、`+mandatory-note` / `+exception`）は**目安**であり、
規則としての読みは `docs/S03_MISSED_TIMING_DESIGN.md` の 1 章にまとめてある。
各件の一次情報は裁定 DB の `sourceUrl`。
**S03-U494 で、「タイミングを逃」という語を含まないのに判定の根拠になる裁定があることが分かった。**
それらは末尾の「S03-U494 で追加参照した当時裁定」節にまとめてある（上の 123 件には数えていない）。

**`cards=[...]` は裁定が載っている Wiki ページの名前であって、発動するカードではない。**
S03-U492 でこれを読み違えた引用を訂正した。例: `WIKI-2B88D7C8D921` と `WIKI-2CF23AA42E79` はどちらも
`cards=['血の代償']` だが、問われているのはそれぞれ**《落とし穴》**（召喚成功後の応答、`answerDate=None`）と
**《神の宣告》《キックバック》《昇天の角笛》**（召喚そのものの無効、`answerDate=2011-08-25`）である。
`answerDate=None` は「本文に回答日が書かれていない」という意味で、取得日（`backupDate`、どちらも 2011-08-26）しか分からない。

# S03-U495 で追加参照した当時裁定（引き方を直してから見つかった分）

## 引き方の訂正 — `cards` 欄だけで引いてはいけない

S03-U494 はカード名を裁定 DB の **`cards` 欄**だけで突き合わせていた。`cards` は**裁定が載っている
Wiki ページの名前**であって、問われているカードとは限らない（S03-U492 で注釈を訂正したのと同じ誤り）。
そのため、**本文で名前が挙がっているだけの裁定が全部見えていなかった**。影響は小さくない。

- 《E・HERO エアーマン》の**タイミングを逃す裁定 2 件**（`WIKI-9FC5B41EDCF4` / `WIKI-0B439F71B94A`）は
  どちらも `cards=['ゴブリンドバーグ']` のページにある
- 《落とし穴》の裁定（`WIKI-2B88D7C8D921`）は `cards=['血の代償']` のページにある

S03-U495 では **`cards` 欄が一致するか、本文の `《…》` の中身が一致する**ものを引く（全角・半角・
長音・中点・空白を正規化してから比較する）。部分一致は使わない — 使うと《奈落の落とし穴》の中の
「落とし穴」まで拾ってしまう。

さらに、本文で名前が挙がるだけの裁定は**共名の可能性がある**ので機械的には数えない。例:
`WIKI-5BD9F5131D7A` は「タイミングを逃す」を含み《宝玉獣 サファイア・ペガサス》の名前も出てくるが、
逃すと書かれているのは《宝玉獣 ルビー・カーバンクル》の効果である。
