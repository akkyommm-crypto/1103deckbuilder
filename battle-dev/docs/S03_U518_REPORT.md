## 1. 当時裁定から組み立てたもの（推測していない）

### 決戦の火蓋
- `WIKI-55C383C128FC`（07/12/10）「《血の代償》と同様に、効果の発動時にはチェーンブロックを作りますか？」→「はい、作ります」
  → 《血の代償》と**同じ共通手順**（`s03BloodOfferTributeThenSummon`、cards/00）を使う。
  手順の中身（リリースの払い方・`NORMAL_SUMMON` prepaid・`onNormalSummon` の発火・召喚無効の窓の印）は変えていない。
- `WIKI-38EC2882E2E0`（08/01/18）除外は**コスト**。→ `cost()` で墓地のモンスターを選んで除外する。
- `WIKI-2AB690FE02B1`（07/12/10）1ターンに複数回発動できる。→ 回数制限を宣言しない（テストで 2 回発動して測った）。
- `WIKI-1330B937F075`（回答日なし）上級モンスターの通常召喚にはリリースが必要。
  → 共通手順が `normalSummonMethodsFor` / `tributeCandidatesForV23` でリリースを払う（星5で測った）。
- このカードの召喚は**ターンの通常召喚権を使わない**（`prepaid`）。テストで `normalSummonUsed` が false のままを測った。

### デビル・フランケン
- 当時の裁定は `wiki-rulings.js` と `rulings-data.js` の**どちらにも 0 件**（カード名・本文の両方で検索）。
  したがってテキストだけを実装し、それ以外は何も主張しない。
- コストで 5000LP を払い、エクストラデッキの融合モンスター1体を攻撃表示で特殊召喚する
  （素材なしの `FX_EX_SUMMON`。《簡易融合》S03-U53 と同じ経路）。
- 融合召喚ではない（テキストは「特殊召喚する」）ので `kind` は `'effect'`。
  その結果 `properlySummonedS03` が付かない＝後から墓地から蘇生できない形になる。これはテストで固定した。
- **未確定（RULING_UNRESOLVED）**: LP がちょうど 5000 の時に払えるかは当時の根拠が無い。
  engine の既存の LP コストには「ちょうどでも払える」側と「より多く必要」側の両方があり、
  ここは最も近い《簡易融合》（S03-U53）と同じ**厳しい側**に合わせた。テストはその読み方を測っているだけで、
  正しいとは主張していない。この不一致は後続課題として記録する。

### クルセイダー・オブ・エンディミオン
- デュアルの「通常モンスターとして扱う」「もう1度召喚」「効果を得る」は S03-U119 の共通機構
  （`defineGeminiS03` / `geminiActiveS03` / `doGeminiSummonS03`）。もう1度召喚するまで効果は発動できない（測定済み）。
- `WIKI-F0C82F8C96D2`（10/12/17）魔力カウンターを乗せるのは**対象を取る起動効果**。
  → 発動時に対象を宣言し、解決時に `API.addCounter`。候補は `counterCapableCardsV22`（engine/1L）で読む。
- `WIKI-7924775F83D7`（10/12/17）「数値アップ後に《スキルドレイン》を発動した場合、上昇数値は失われますか？」→「失われます」
  → 攻撃力 600 アップは**このカード自身の継続効果**にした（`continuous scope:'self'` ＋ ゾーン限定のターン刻印）。
  `continuousSources()` は効果が無効な出所を除くので、後からスキルドレインを出した瞬間に 1900 へ戻る。
  解決時に一度だけ加算する `mods` では、この裁定は再現できない（後から無効にしても残る）。
  刻印 `u518CrusaderBoostS03` は `ZONE_LOCAL_KEYS` に入れたので、場を離れる・裏側になると消える。

## 2. 共通処理に足したもの（最小限）

`cards/00_generic_core.js` の `s03BloodOfferTributeThenSummon(p, targetCard, method, db, chosen, labelS518)` に
カード名の引数を足した。省略時は従来どおり「血の代償」。ログ・選択の表題・リリースの理由だけが差し替わり、
手順そのものは変えていない。既存の呼び出し 2 か所はそのまま。

## 3. 実経路で測ったこと

`tools/test_s03_u518_summon_rights.js`（22 PASS）。Replay 監査は 5 場面。

- 決戦の火蓋: 墓地のモンスターを除外して手札の通常モンスターが通常召喚され、通常召喚権は残る／同じターンに 2 回／
  星5はリリース1体を払って出る／negative control 3 件（リリースを払えない星5だけの手札・墓地が空・相手のターン）。
- デビル・フランケン: LP 8000 → 3000 で融合モンスターが攻撃表示で出る／正規の特殊召喚にはならない／
  negative control 2 件（LP ちょうど 5000・エクストラデッキに融合モンスターがいない）。
- クルセイダー: もう1度召喚するまでは発動できず攻撃力 1900 のまま／もう1度召喚後に対象へ魔力カウンター 1 つと
  攻撃力 2500／2 回目は 1ターンに1度で止まる／スキルドレイン発動で 1900 に戻りカウンターは残る。

関連テストも通過: u119（34）・u122（18）・u148（23）・u500（35）・u53（16）・u104（12）・u105（8）・u09（18）・
u487（32）・counter_v22（44）・u14（50）・u219（14）。件数を固定している主張は動いていない
（3 枚とも召喚誘発・破壊誘発を持たないため）。

## 4. 未対応・後続課題

1. デビル・フランケンの「ちょうど 5000」問題（上の RULING_UNRESOLVED）。engine 全体の LP コストの読み方が
   2 種類あるので、当時の根拠を見つけてから一括で揃える。
2. S03-U517 から持ち越し: `TOKEN_CREATE` が召喚制限を見ないため、トークンの特殊召喚は召喚制限で止まらない。
   複数体を出す効果の「発動」可否も、何体出すかの情報が無いので判定できない。
