# S03-U506 報告：破壊が条件の誘発を入れた（5-a 項目 4 の破壊側）

S03-U505 の監査で確定した設計書 (F) のうち、**破壊（D）の側だけ**を入れた。
墓地送り（G、「時」と読める 112 枚）は別単位のままである。

## 1. 入れたもの

| 要素 | 内容 |
|---|---|
| (B-2) の正規表現 | `(?:に成功した|された|られた|した)(時|場合)`（**「られた」を足した**。これが無いと「墓地へ送られた時」に 1 件も当たらない）|
| (B-2) の語 | `戦闘で破壊`=B / `破壊`=D / `フィールドから墓地へ送`=GF / `墓地へ送`=G / `除外`=X / `リリース`=T |
| (B-3) の種別 | `MISSED_TIMING_DESTROY_CLASS_S03 = {onDestroy:'D'}`、`MISSED_TIMING_CLASSES_S03.destroyed = true` |
| (B-5) の許可リスト | **1 件だけ**。《スネーク・ホイッスル》（`WIKI-9E5470176D20`、**回答日 2009-08-07**、basis A）|

**配線とテキストを合わせる**（R9 と同じ作法）。`onDestroy` で拾った候補は「破壊された時」の句だけを見る。
だから《森の番人グリーン・バブーン》（配線は `onDestroy` だが句は「墓地へ送られた時」）には種別が付かない。
`onLeaveField` は種別に入れていない（S03-U501 / U502 で見たとおり盤面の差分から検出されるルール処理で、別の軸）。

**negative control（全 4996 枚で固定）**: 召喚句（N/S/F/R）の件数とカードごとの判定が S03-U505 時点と
**完全に同じ**（N 239時/49場合、S 213/53、F 75/8、R 20/35、召喚語の出現数 692）。
語を足しても召喚語の割り当ては 1 文字も変えていない。

## 2. 実装して初めて出た (A) の欠陥を直した

**破壊だけで終わる《地砕き》でも《スネーク・ホイッスル》が落ちていた。**
原因は (A) の処理の許可リストに `FX_SELF_TO_GRAVE`（**発動した魔法・罠が解決後に墓地へ送られる
ルール上の行為**）が入っていたことである。

- 発行しているのは `engine/20` afterEffect・`engine/30` afterPreparedResolve・`engine/40` afterResolve・
  `engine/70`・`engine/1U`（発動を無効にされた分）の **5 か所だけで、すべてそのカード自身の後片付け**
  （全件確認。テスト D3 で固定）。
- 当時裁定もこれを処理に数えていない。`WIKI-1B4D52FCA757`（**回答日 2010-08-11**）は
  《グリフォンの羽根帚》（通常魔法）で《歯車街》を破壊した場合に逃す理由を
  「破壊後に**回復の処理**が挟まるので」と説明しており、**魔法が墓地へ行くこと自体は挙げていない**。
  `WIKI-25B0FF09EA0C`（**回答日 2009-02-22**）も「効果はカードが破壊されたというタイミングで終了するため…
  発動する事ができます」と答えている。
- → **許可リストから外した。**

召喚成功の種別では影響が無かった（解決中の特殊召喚成功は `flushResolutionSummonBatchV2` が
リンクの解決の最後に刻むため。S03-U504 で実測）。破壊の種別を入れて初めて実経路に出た欠陥である。

この修正で、実測していた刻みの数が 1 つ減った経路がある（《血の代償》チェーン2 が 2→5 から **2→4**）。
質的な事実（チェーン2 では召喚の後に番号が進む）は変わらないので、S03-U497 の D2・D3 と
S03-U498 の C2 の**数値だけ**を直した。

## 3. 実測した結果（当時裁定どおり）

| 場面 | 刻み | 結果 |
|---|---|---|
| 《地砕き》（破壊だけで終わる）| `MOVE` 0→1 / `FX_TO_GRAVE` 1→2 | 《スネーク・ホイッスル》は**発動できる**（デッキの爬虫類族を特殊召喚）|
| 《ソウルテイカー》（破壊の後に回復）| `MOVE` 0→1 / `FX_TO_GRAVE` 1→2 / `LP` 2→3 | **タイミングを逃す**（伏せたまま残る）|

後者が `WIKI-9E5470176D20`（**2009-08-07**）と `WIKI-1B4D52FCA757`（**2010-08-11**）の形である。

## 4. 公開対象の対応範囲と未対応範囲

### 対応した範囲

- 破壊が条件の任意誘発のうち、**当時の根拠を確認できた 1 件**（《スネーク・ホイッスル》）だけがタイミングを逃す。
- (A) から `FX_SELF_TO_GRAVE` を外した（全カードに効く修正。発動した魔法・罠の後片付けは処理ではない）。
- 「破壊された**場合**」のカードは落ちない（`WIKI-17DDC86F4023` **2009-05-14** どおり）。

### 未対応範囲

- **墓地送り（G）の家族**: 句は読めるようになったが、G を見るイベントがまだ無いので **1 件も落ちない**
  （「時」と読める 112 枚）。除外・リリース・戦闘で破壊も同じ。
- 「逃す」側の残り 11 枚。内訳（S03-U506 で実測）: 未実装 5 枚（《ユベル》《ブランチ》《ブラック・ブルドラゴ》
  《鋼核合成獣研究所》《セブン・ソード・ウォリアー》）、配線が `onLeaveField`（《ボタニティ・ガール》《機皇城》）、
  配線が無い（《歯車街》《ヴァイロン・エレメント》）、句が G（《森の番人グリーン・バブーン》）、
  **強制誘発なので R1 と衝突する**（《虚無空間》。当時裁定は逃すと答えているが R1 は「強制は逃さない」なので
  別に決める必要がある）。
- 《黒衣の大賢者》は **R6（調整中）** として落とさない。
- **タイミングを逃す判定は確認済み 45 枚 / 66 組に限られ、全カード・全タイミング規則が完成したわけではない。**
