# S03-U465 - スーペルヴィス

基点: `codex/battle-u465`。既存のデュアル再度召喚と装備スコープを接続し、旧 `ENGINE_GAP` を解消した。

## 実装

- 表側デュアルモンスター（両フィールド）だけを対象にする実装備魔法の発動。
- 有効な装備ソースが存在する間だけ、装備先を「もう1度召喚された状態」として動的に扱う。
- 表側表示でフィールドから墓地へ送られた場合、自分の墓地の通常モンスターを対象にして表示形式を選び特殊召喚する。
- 装備カードの無効化・除去で効果を即時失効し、`dualUp` は書き込まない。

## 検証

- Negative control（U464ビルド + U465テスト）: **5 FAIL**（既存エンジンでは装備発動・デュアル化・蘇生が未実装）。
- 修正後: U465 **8 PASS / 0 FAIL**。
- 実経路: 手札発動、対象選択、装備、効果無効、サイクロンによる破壊、任意誘発、墓地対象、表示形式選択、Replay audit。
- 回帰対象: U119/U148/U463 のデュアル、U233/U312 の装備、U464 のモンスター装備。
