# S03-U462 - インヴェルズの門番

基点: `codex/battle-u459` の U459-U461（GitHub Actions Battle verification 成功）。古い `codex/invellz-gatekeeper` の実装をそのまま移さず、最新の追加召喚プリミティブへ必要部分だけを移植した。

## 実装

- 表側の《インヴェルズの門番》が、リリースを伴う表側の「インヴェルズ」通常召喚成功を確認した場合だけ、そのターンの追加通常召喚権を得る。
- 追加権は通常召喚とセットのどちらにも使用できる。
- 複数の門番がいても追加権は共有で1回だけ。追加アドバンス召喚で門番自身をリリースできる。
- 条件成立前の通常召喚・非インヴェルズのアドバンス召喚・裏側の門番は権利を作らない。成立後に門番が裏側になった場合も古い権利は戻らない。
- 条件成立は門番カード上のターン値、使用済みはプレイヤーの共有キーとして保存し、Save/Replay可能なJSON状態だけで表現した。
