# S03-U529 — 《ダーク・シムルグ》

カード実装の計画の 18 単位目。「相手はカードをセットできない」を共通側の既存のセット禁止
（`setBannedS03`、S03-U392 の大寒波）に申告制で足し、セットの 3 経路で見るようにした。
S03-U524 の報告書に残していた後続課題（ダーク・シムルグのセット禁止）をこれで閉じている。

## 1. 共通側に足したもの（最小限）

`engine/1ZZT_set_ban_s03.js`

- `setBannedS03(gs, P)` は大寒波のターン範囲だけを見ていた。永続効果による禁止を足した:
  相手のフィールド（モンスターゾーン・魔法＆罠ゾーン・フィールドゾーン）に、スクリプトが
  `setBanOpponentS03:true` を申告した**表側表示**のカードがあり、その効果が無効になっていなければ、
  そのプレイヤーはセットできない（`setBanSourceS03`）。申告の無いカードでは何も変わらない。
- セットの経路は 3 つあり、すべてで見るようにした:
  - `SET_ST`（魔法・罠のセット）… 既に `setBannedS03` を見ていた。
  - `SET_MONSTER`（モンスターのセット）… 追加した。
  - `FX_SET_STATE` で裏側守備表示にする処理… 追加した。**発動した側**が禁止されている場合だけ止める
    （発動者は解決中のカードの印 `a.srcS03`（engine/1ZG）から引くので Replay でも同じ値になる）。
    これで WIKI-7D588C652FDC（10/03/25、自分は相手モンスターを対象に《月の書》を発動できる）と
    WIKI-B5978DD4B6F1（08/10/03、相手は《皆既日蝕の書》を発動できない）の向きが分かれる。
- 《くず鉄のかかし》（既存カード）を 1 か所直した: セットできない場合は墓地へ送る
  （WIKI-A6BBE85B1591 08/03/15。攻撃無効の効果自体は有効）。

## 4. 未対応・後続課題

1. `WIKI-8498FE1224BA`（09/03/05）/ `WIKI-BBF7BDC4431C`（09/07/21）《ＤＮＡ移植手術》で属性を宣言された
   場合は宣言した属性のみになる → engine の `currentAttributesV17` は属性の上書き（attrOverride）があっても
   `additionalAttributes` を足すので、神属性を宣言された場合に一致しない。**未対応**。
   直すと《光と闇の竜》にも影響するので、別単位で測ってから変える。
2. `WIKI-787E4D7D65EC`（08/01/21）のうち「任意でセットする効果は発動自体できない」は**未対応**。
   止めているのはセットの処理（engine のセットの経路）なので、強制効果の挙動は裁定どおりだが、
   任意効果は発動できてしまう（そのカードごとに条件で見る必要がある）。
   `WIKI-DA60BC8DAB00`（08/01/21）《浅すぎた墓穴》がお互いに発動できない事も同じ理由で**未対応**。
3. `WIKI-BDCEC9BCB710`（08/01/21）相手のサイクル・リバースモンスターの効果が発動できない事は**未測定**。
4. `WIKI-6EDF841E9DFF`（11/04/16）除外されたカードをセットする効果（《スペースタイムポリス》）も
   止まる事は**未測定**（セットの経路は共通なので同じ判定に乗る見込み）。
5. `WIKI-07B39F4CDF79`（10/09/04）《虚無空間》をチェーンされた場合に手札に残る事は**未測定**
   （engine の既存の不発処理のまま）。
