# S03-U511 召喚無効の破壊に「破壊したプレイヤー」を記録した

## 何を直したか

S03-U509 / U510 で、召喚を無効にされたモンスターは「破壊され墓地へ送られた」扱いになった。
しかし破壊したプレイヤー（`byPlayer`）は `null` のままで（実測）、
「**相手によって**破壊され墓地へ送られた場合」を条件とする効果が発動できなかった。

当時裁定 `WIKI-D70393946D93`（**回答日 2010-09-16**、掲載ページ《聖騎士ジャンヌ》）:

> Q: 《神の警告》で召喚を無効にされるなど、**フィールド上以外で破壊され墓地へ送られた**場合、
>    効果は発動できますか？
> A: はい、発動できます。(10/09/16)

《聖騎士ジャンヌ》②は「このカードが**相手によって**破壊され墓地へ送られた場合」なので、
この裁定は「召喚無効の破壊は相手による破壊である」ことまで含んでいる。
同じ向きの二次資料（**回答日なし**）に `R1103-SCRAPDRAGON-004` がある。

## 入れた形

1. `summonNegatePendingV2`（`engine/30`）が、無効にした側を 1 か所で決めて Action に載せる。
   実測: その時点で chain はすでに空で `destroyerPlayerV30` は `null` を返すが、
   `RESOLVING_LINK_S03` と `P3_EFFECT_CONTEXT` はどちらも無効にした側を指している。
2. `SUMMON_WINDOW_NEGATE_V42`（`engine/00`）が `pendingSummon` に控える。
   Action に載っているので Journal 再生でも同じ値になる。
3. 取り消しの破壊 4 経路（`engine/40` の反転召喚・手札、`engine/1ZZY` のデュアル再召喚・解決中）が
   `byPlayer` として渡す。**申告が無ければ今までどおり付かない。**
4. 《聖騎士ジャンヌ》の判定を、フィールド上以外の破壊にも当たるようにした。
   場での破壊の判定（`c1DestroyRecord` を使う枝）は **1 文字も変えていない**。

## 対応した範囲（公開できる範囲）

| 場面 | 結果 |
|---|---|
| 手札から出した通常召喚を《神の宣告》で無効 | 破壊の記録は `from:'hand'` / `byPlayer:1`。②を発動できる（この単位の前は発動できなかった）|
| 反転召喚を無効 | `from:'mz'` / `byPlayer:1`。②を発動できる |
| 解決中の通常召喚（S03-U510 の経路）を無効 | `byPlayer:1`。②を発動できる |
| 場で相手の《地砕き》に破壊（従来経路）| 変わらない |
| 《クリッター》（「フィールドから墓地へ送られた場合」）| 相変わらず発動しない |
| 《人造人間－サイコ・リターナー》（破壊者を問わない）| 今までどおり発動する |

## 未対応の範囲

1. **シンクロ召喚の無効**（`WIKI-6745DCCBE047` 10/07/18・`WIKI-EFE5568A43B4` 10/05/18）は対象外。
   エクストラデッキから出る召喚の窓はこの単位でも触っていない。
2. 「相手によって破壊され」を条件とする**他のカードの判定**が、`graveInfo.from === 'mz'` や
   `c1DestroyRecord` に縛られていないかは**全件確認していない**。この単位で直したのは、
   当時裁定の当事者である《聖騎士ジャンヌ》1 枚だけである。
3. 自分で自分の召喚を無効にする経路（あれば）の裁定は**確認していない**。

## テスト

`tools/test_s03_u511_negated_summon_destroyer.js`（A エンジンの形 2・B 当時裁定の場面 4・
C negative control 4・D ソースの形 3・E 文書と登録 3、Replay 監査 6）。
書き換えた既存の主張は 2 件で、どちらも**ソースの形**を見ている主張である。
取り消しの破壊 4 経路に `byPlayer` を渡すため `act(...)` を `Object.assign(...)` で包んだので、
`tools/test_s03_u500_gemini_resummon_negation_window.js` の G1 と
`tools/test_s03_u509_negated_summon_destroyed.js` の C3 が探していた文字列が一致しなくなった。
**弱めていない** — 見ている内容（枝が分かれていること、未到達の申告が手札からの召喚の枝にだけ付くこと、
手札に戻す枝と反転召喚の枝が新しい枝より前にあること）は同じままで、探し方だけを新しい形に合わせた。
理由はテストの中にも書いてある。
