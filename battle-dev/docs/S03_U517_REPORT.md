## 2. 共通処理（最小限）

1. `engine/00_state_actions.js`：通常召喚の回数を数で表す。`temporaryFlags.normalGrantS03` が上限、
   `normalGrantUsedS03` が基本の召喚権より後に使った回数。`normalGrantMaxS03` が上限の最大値を返す。
   S03-U274 の `doubleSummonS03`（1 = 使える / 2 = 使った）はそのまま観測できる形で残した。
2. `engine/1ZZS_summon_lock_s03.js`：1 ターンの召喚行為の数（`bumpSummonActS03` / `noteSummonActS03` /
   `summonActsThisTurnS03`）。置き場は `temporaryFlags.summonActsS03` なので、ターンの切り替えで消え、
   Journal・保存・Replay の digest にも入る。数える点は召喚成功イベントの予約（`EVENT_QUEUE_V31` と
   `queueDeferredEventV2` の即時分岐、`EX_SUMMON_COMMIT_V42`）と反転召喚の reducer（`FX_SET_STATE` の `flipSummon`）。
3. `engine/1ZZS` + `engine/40`：`globalSummonLockS03` — モンスターを問わない特殊召喚の封じを
   `v46GlobalSpecialSummonRestrictionReason` から読む。これで「特殊召喚を目的とする効果」の発動も止まる。
4. `engine/1ZZS`：罠である召喚ロック源は、効果が無効の間は何も適用しない（上の 11/05/30 の裁定）。
   既存の《暴君の自暴自棄》（永続罠の `summonLockS03`）にも同じ修正が効く。

## 3. 実経路で測ったこと

`tools/test_s03_u517_summon_counts.js`（37 PASS）。Replay 監査は 10 場面。

- カイザーコロシアム：お互い 1 体ずつで相手の通常召喚が止まる／コロシアム側が 0 体なら止まらない（negative control）／
  コロシアム側が 2 体なら 1 体目は通り、並んだ後は止まる／《簡易融合》は発動自体ができない／
  数を超えないときは同じ《簡易融合》が通って融合モンスターが出る（negative control）。
- サモンリミッター：召喚行為が 1 回ずつ数えられ 3 回目が止まる／理由がカード名で示される／数はプレイヤーごと／
  反転召喚も数える／伏せたまま 2 回召喚した後に発動すると 3 回目が止まる（発動前の分も数えている）／
  サイコ・ショッカーが表側の間は 3 回目も通る。
- サモンチェーン：チェーンが無い時は発動できない／実経路のチェーン 3（強欲な壺 → 強欲な瓶 → サモンチェーン）で
  発動でき、通常召喚が 3 回まで行える／《二重召喚》と両方でも 3 回まで（4 回目は増えない）／
  同一チェーン上に同名カードが 2 つ並んでいる間は応答に出てこない。
- 召喚行為の数はターンの切り替えで 0 に戻る。

## 4. 未対応（この単位では直していない。測って確認した残り）

1. **トークンの特殊召喚**は `TOKEN_CREATE`（engine/00）が召喚制限を一切見ないので、どちらの制限も止めない。
   - カイザーコロシアム：`WIKI-CA7FC24FF02B`（11/08/22）「冥府の使者カイエントークンは特殊召喚できません」。
   - サモンリミッター：`WIKI-04F14179580E`（09/10/30）既に 2 回行っているプレイヤーのローズ・トークンは特殊召喚されない。
   トークンを素通りさせているのは S03-U429 の設計（《ワーム・ベイト》《迷える仔羊》《スライム増殖炉》のように
   「このカードの効果以外では召喚できない」カードが自分のトークンを出せるようにするため）で、
   直すには「解決中のカード自身のロックは除く」という例外を `TOKEN_CREATE` に入れる必要がある。後続課題。
2. **複数体を出す効果の発動の可否**は、効果が何体出すかという情報がスクリプトにないので決まらない。
   カイザーコロシアムは《スケープ・ゴート》（4 体）《異次元からの帰還》《レスキューキャット》（2 体）
   剣闘獣の特殊召喚の**発動**を止めない（`WIKI-05D8FDD9315F` は 1 体分の判定では再現できない）。
   1 体分の判定（= 数が並んでいる状態）は実装済みなので、止まるのは「1 体出す効果」までが現状。後続課題。
3. 上の 2 つがあるため、カイザーコロシアムとサモンリミッターは **PARTIAL** とした（実装済みとは数えない）。
   サモンチェーンはテキストの全効果を実装・検証したので TESTED。
