# S03-U464 - 進化の繭

基点: `codex/battle-u462` の U463 ローカルコミット。既存の手札モンスター装備APIと装備元スコープを利用した。

## 実装

- 自分メインフェイズに手札の《進化の繭》を発動し、自分フィールドの表側表示《プチモス》へ装備カード扱いで装備する。
- 装備中の《プチモス》の攻撃力・守備力を《進化の繭》の元々の数値（0/2000）として扱う。
- 装備が外れた場合は即座に《プチモス》本来の300/200へ戻る。対象不在、裏側の《プチモス》、魔法・罠ゾーン満杯では発動操作を出さない。

## 検証

- Negative control（U463ビルド + U464テスト）: **4 FAIL**。
- 修正後: U464 **9 PASS / 0 FAIL**。
- 実DUELの手札発動、対象情報のチェーン保持、モンスター装備化、動的な攻守、装備除去後の復帰、3種類のnegative control、装備前後のReplay digestを確認した。
- 近接回帰として、手札モンスター装備APIを使うU402および装備関連テストを実行する。
