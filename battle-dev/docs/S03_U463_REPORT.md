# S03-U463 - 超合魔獣ラプテノス

基点: `codex/battle-u462` の U462 ローカルコミット。既存のデュアル召喚機構と無効化済み永続効果の収集機構を接続した。

## 実装

- 表側で有効な《超合魔獣ラプテノス》がモンスターゾーンにいる間、両プレイヤーの表側デュアルモンスターを「もう1度召喚された状態」として扱う。
- 対象カードへ `dualUp` を書き込まず、`continuousSources()` から現在の効力を毎回導出する。ラプテノスが無効・裏側・場外になれば即座に失われ、元から `dualUp` のカードだけは維持される。
- ラプテノスで効果が有効なデュアルには、重ねて「もう1度召喚」操作を表示しない。
