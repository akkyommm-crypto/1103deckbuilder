## 1. 当時裁定から組み立てたもの（推測していない）

### 世紀の大泥棒
- `WIKI-6FD2C17EEAE9`（10/07/04）「相手の手札が0枚の時にこのカードが相手に戦闘ダメージを与えた場合も
  カード名を宣言する必要がありますか？」→「はい、その場合でもカード名を宣言します」
  → 誘発条件に手札の枚数を入れない。宣言は強制で、捨てる処理だけが空振りになる。テストで 0 枚でも宣言される事を測った。
- 「度に」なので回数制限を付けず、強制効果（`forced:true`）。宣言は効果の解決時（コストではない）。
  宣言はカード一覧からの journaled な選択（《マインドクラッシュ》が発動時に行うのと同じ仕組み）で、
  同名の判定は `sameCanonicalCardV4`（同名異カードを取りこぼさない）。

### 天狗のうちわ
- `WIKI-F921368DD337`（10/09/17）「この効果にチェーンブロックは作られますか？」→「チェーンブロックを作ります」
  → 永続効果ではなく**誘発効果**として実装（表側の永続罠が、レベル2以下のモンスターの反転召喚に強制で誘発する）。
  他のカードの反転に反応するので `onOtherFlipS03`（S03-U225）を宣言する。カードの発動自体は効果を持たない
  （S03-U10 の分類表 `CARD_ACTIVATION_FREE_V32` に登録）。
- `WIKI-FD3CC99C4815`（09/01/03）「発動が制限されるのはリバース効果のみですか？」→「いいえ、違います」
  → 封じは S03-U217 の `activationLockS03` で、**モンスター効果のフィールドでの発動すべて**を対象にする。
  条件は「反転召喚された記録（`flipSummonedTurnS03`、S03-U260）が今ターン」かつ「レベル2以下」。
  封じは誘発候補を集める段階で効くので、同じ反転召喚に対する「この時」の封じとして働く。
