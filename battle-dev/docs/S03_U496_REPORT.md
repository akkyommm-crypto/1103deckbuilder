## 1. 何を変えたか

(B-2)(B-3) は「現行テキストの文言 ＋ 配線」で落とす候補を決めていた（**290 組**）。
S03-U494 / U495 の照合で、そのうち当時の根拠で裏付けられているのは一部だけだと分かった。
S03-U496 では、当時の根拠から**該当効果**について次の 3 つを確認できた（カード, イベント, 効果）だけを落とす。

1. **任意性** — 当時裁定が「発動しない事は可能」と答えている、または当時テキストのその文が「できる」
2. **発動条件** — 「〜に成功した時」であること（当時裁定の引用、または当時テキスト）
3. **例外が無いこと** — 強制でない（R1）／召喚無効でない／当時裁定が**調整中**でない（R6）／
   R5・R10 の宣言が無い／リバース効果ではない（R8）

**許可リストに無いものは落とさない。** 判定の順番は
`刻み → R5/R10 の宣言 → R1 強制 → 召喚無効 → **(B-5) 許可リスト** → (B-2)(B-3) 文言と配線`。
許可リストは最後の歯止めとして足したので、**確認済みの修正は 1 つも戻していない**。

落とす組は **290 → 65（44 枚）**。

### 2-3. 効果単位の管理（条件3）

許可リストは**カード名 → イベントの配列**で持ち、必要なら**イベントごとの効果キー**（`keys`）を指定できる。
1 つのイベントに複数の効果が配線されているカードは実測で 1 枚だけで、
**《アルカナフォースIII－THE EMPRESS》の `onNormalSummon`**（`coin` 強制 / `heads-summon` 任意 /
`tails-discard` 強制）。この 1 枚は許可リストに入れていない。
`keys` を書かないまま複数効果のイベントに当たった場合、また候補の効果キーが決められない場合は
**落とさない**（`missedTimingConfirmedS03`）。候補の効果は `ctx.v4EffectKey` から取る。
