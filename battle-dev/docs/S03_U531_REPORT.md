# S03-U531 — 《融合解除》

カード実装の計画の 20 単位目。「その融合モンスターの融合召喚に使用した融合素材」が engine に
残っていなかったので、その記録と後片付けを共通側に足した。あわせて、蘇生制限の扱いを 1 か所直した。

| カード | 種別 | これまで | この単位 |
|---|---|---|---|
| 融合解除 | 速攻魔法 | NOT_STARTED | TESTED |

## 1. 共通側に足した／直したもの

1. 融合召喚の成功時に、出た融合モンスターへ**使用した素材の uid** を記録する（`fusionMatUidsS03`、engine/1ZL）。
   既存の `fusionMaterialS03` は素材側に「発動した魔法名」を書くだけで、どの融合モンスターの素材かが
   分からなかった。記録はゾーン限定にしていない（WIKI-6F274903FD7E: 一時的に除外されて戻った場合も使えるため）。
2. 融合召喚以外の方法で特殊召喚された時にその記録を消す（engine/00 の `FX_SPECIAL_SUMMON`）。
   「戻すだけ」の処理は `returnS03:true` を載せて消さない。《亜空間物質転送装置》の戻しに 1 行足した。
3. **蘇生制限の扱いの訂正**（engine/1ZK）。「○○召喚でしか特殊召喚できない」は蘇生制限なので、
   正規にその方法で出た後（`properlySummonedS03`）は他の効果でも墓地・除外から特殊召喚できる（`soft`）。
   これまでは融合・シンクロ・エクシーズモンスターを《死者蘇生》等で出す事が一切できなかった。
   WIKI-5772E54131CD（10/11/04）は「《死者蘇生》で出した融合モンスターに《融合解除》を使っても
   素材は出せない」という裁定で、**出せる事自体を前提にしている**。エクストラデッキ・手札・デッキの
   カードは `properlySummonedS03` が掃かれるので、そちらは従来どおり止まる。

## 2. 当時裁定から組み立てたもの（推測していない）

- `WIKI-5772E54131CD`（10/11/04）融合召喚以外で出た融合モンスターでは素材を出せない → 記録を消す。
- `WIKI-6F274903FD7E`（10/11/04）一時的に除外されて戻った場合は出せる → 記録を残す（戻しでは消さない）。
- `WIKI-D359E2863E30`（10/11/04）後から墓地に戻した素材では出せない → 記録した uid そのものを見る。
- `WIKI-91526184443C` 一組を全て出せない場合は 1 体も出せない → 全員が自分の墓地にあり、全員を出せる
  （空きゾーンと特殊召喚の可否）時だけ出す。
- `WIKI-23A6E39C389D`（09/11/21）同名素材が複数でも一組が揃っていれば出せる → uid で数えるので満たす。
- `WIKI-2DC70EF9977F`（07/08/22）/ `WIKI-9066E3EF4316` 融合召喚でない特殊召喚の素材は出せない
  → 記録が付かないので何も起きない。
- `WIKI-47FAE46FE5EF`（08/11/04）フィールドを離れた後に処理をはさむ効果は発動する
  → engine の既存の「場を離れた時」の誘発のまま。

## 4. 未対応・後続課題

1. `WIKI-E962247E640E` / `WIKI-4B24CC5AEDD6`（10/06/25）《プロト・サイバー・ドラゴン》は墓地では
   《サイバー・ドラゴン》として扱われないので出せない、`WIKI-D7F2FCEEA25F`（10/06/25）《沼地の魔神王》は
   出せるが《ファントム・オブ・カオス》《Ｅ・ＨＥＲＯ プリズマー》は出せない
   → この実装は「融合召喚に使った uid そのもの」を見るので、名前の扱いの差は現れない。
   実際の挙動は「使った素材そのものが墓地にあれば出す」なので、代用素材でも出てしまう。**未対応**。
2. 融合モンスターが相手フィールドに居る場合も対象にできる（テキストどおり）が、素材を出すのは
   常に自分フィールド・自分の墓地の一組である。相手の融合モンスターを対象にした場面は**未測定**。
3. 上の 1-3（蘇生制限を soft にした訂正）は融合・シンクロ・エクシーズの全てに効く変更なので、
   既存の融合関係テスト 16 本と全体ゲートで確認した。シンクロ・エクシーズ側の個別の測定は**未測定**。
4. S03-U517〜U530 から持ち越しの項目は各報告書のとおり。
