# S03-U499 報告：《デュアル・サモナー》の効果による通常召喚にも召喚無効の窓を開いた

S03-U498 で入れた召喚無効の窓（`engine/1ZZY_summon_negation_window_s03.js`）の **2 件目の呼び出し元**。
機構は許可リストで、印（`summonNegWindowS03:true`）を付けた呼び出し元だけが窓の対象になる。
S03-U498 は《デュアル・サモナー》を 5-a #1-g として未対応に残していた。理由は
「この召喚は解決中の**選択の再開**の中で行われ、相手のエンドフェイズという別の進行の上に乗っているので、
《血の代償》と同じ順になるかを実測していない」だった。**この単位では先に実測し、同じだと確かめてから印を付けた。**

## 1. 実測（印を付ける前）

| 実測 | 結果 |
|---|---|
| `onNormalSummon` が積まれる時点 | `procStepS03` **2**・chain **0**（《血の代償》チェーン1 と同じ）|
| `NORMAL_SUMMON` の前後 | **1 → 2** |
| 排出時の処理番号 | **2**（刻みと同じ ＝ R4 の比較が成立して窓が開く）|
| 解決中の選択（どのデュアルモンスターを召喚するか）| `CHOICE_OPEN_V49` / `CHOICE_ANSWER_V49` は処理番号を**進めない** |
| デュアル再召喚の枝（`GEMINI_SUMMON_S03`）| 処理順は手札の枝と**同じ**（`procStepS03` 2 で積まれる）|

## 2. 根拠

- `WIKI-2CF23AA42E79`（**回答日 2011-08-25**、掲載ページ《血の代償》）は
  「**この効果による通常召喚**に対し…召喚を無効にするカードを発動できますか？」→「チェーン１で行われている
  ならば、発動可能です。…」と、**効果による通常召喚一般**の形で答えている。
- **このカード自身の召喚無効の裁定は無い。** 裁定 DB にある《デュアル・サモナー》の 2 件は
  `WIKI-A16DF4FA6D7D`（07/12/22、上級モンスターのリリースの要否）と
  `WIKI-C73F488783A0`（08/06/24、セット）で、どちらも召喚無効の話ではない。
  個別裁定が無くても当時テキスト＋一般則で確認できる範囲として入れている。

## 3. 入れたもの

`cards/HZK_claude_s03_u164_dual_summoner.js` の**手札からの枝 1 箇所**に印を付けただけ。
engine には手を入れていない（S03-U498 の機構をそのまま使う）。カード先頭のコメントにあった
「a summon made during a resolution has no summon-negation window」は実態と合わなくなったので、
実測した処理順と、再召喚の枝を外した理由に書き換えた。

## 4. 公開対象の対応範囲と未対応範囲

### 対応した範囲

- 《デュアル・サモナー》が**手札から**デュアルモンスターを通常召喚するときの召喚無効の窓。
  チェーンは 1 本（このカードの効果）なので、召喚の後に別の処理が無ければ開く。
- リリースを伴う上級デュアルモンスター（《ギガプラント》）でも開く。
- 無効にしたときの結果は S03-U498 と同じ（墓地へ `MOVE`、召喚成功のイベントを落とす、
  破壊でも「フィールドから離れた時」でもない）。《デュアル・サモナー》自身は場に残る。
- 窓を跨ぐ Save/Load（別 VM）と Replay 監査。

### 未対応範囲（**挙動は S03-U498 のまま**）

- **デュアル再召喚（「もう1度召喚」、`GEMINI_SUMMON_S03`）を効果で行う枝**（5-a #1-h）。
  処理順は同じだが、**取り消しの形が違う**: 既存の `geminiSummonResumeS03`（`engine/1ZI`）は
  commit で `GEMINI_SUMMON_S03` を**適用し**、cancel ではモンスターを**破壊する**。
  S03-U498 の案 (b) は召喚を適用済みにするので、そのままでは commit が二重適用になる。
  UI 起点のデュアル召喚にはいまも窓が開く（そこは変えていない）。
  根拠も `WIKI-5B32D377CFE9`（**回答日なし**）の「再度召喚は通常召喚扱い」までで、
  再度召喚に対する召喚無効そのものの裁定は裁定 DB に無い。
- S03-U498 からの未対応はそのまま: 解決中の**特殊召喚**（#1-d）、窓の中身の 2 点（#1-e / #1-f）、
  案 (b) の近似 2 点。**タイミングを逃す判定は確認済み 44 枚 / 65 組に限られ、
  全カード・全タイミング規則が完成したわけではない。**
