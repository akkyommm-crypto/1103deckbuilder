# S03-U509 召喚を無効にされたモンスターを「破壊され墓地へ送られた」扱いにした

## 何を直したか

S03-U501 で、召喚を無効にされたモンスターの行き先が当時裁定と食い違っていることを実測した
（5-a #1-j）。手札から出した召喚を無効にすると、取り消しが素の `MOVE` だったため

- そのモンスターのイベントが **1 つも積まれず**（`onDestroy` も `onSendToGrave` も無い）、
- `graveInfo` も付かなかった。

当時裁定は「**破壊され墓地へ送られた**」として扱う。

| 裁定 | 回答日 | 内容 |
|---|---|---|
| `WIKI-EFB088FAC57A` | **2010-05-17** | 「《神の宣告》でアマゾネスの召喚を無効にし破壊され墓地へ送られた時も、効果を発動できますか？」→「はい、その場合でも発動できます。」 |
| `WIKI-0A19E6117879` | **2010-06-05** | 《人造人間－サイコ・リターナー》「召喚などを《神の宣告》などで無効にされ墓地へ送られた場合でも効果は発動できますか？」→「はい、できます。」 |
| `WIKI-D70393946D93` | **2010-09-16** | 《聖騎士ジャンヌ》「**フィールド上以外で破壊され墓地へ送られた**場合、効果は発動できますか？」→「はい、発動できます。」 |

同時に、**フィールドで破壊された扱いにはしてはいけない**
（`WIKI-643A78AB3480` **2008-03-19**・`WIKI-9E991E9B14E9` **2010-04-21**）。

## 入れた形

設計 (E) は「`onDestroy` / `onSendToGrave` は積み、`onLeaveField` は積まず、フィールドでの破壊の判定には
当たらない **3 つ目の取り除き方**が要る」と書いていた。実測したところ、その形は**すでにエンジンにあった**。
`FX_TO_GRAVE` は CODEX-C09 で手札・デッキのカードの破壊に対応していて、zone `'hand'` ＋ `byDestroy` で
呼ぶと次のようになる（S03-U509 で実測）。

| 項目 | 結果 |
|---|---|
| `graveInfo` | `{from:'hand', byDestroy:true}`（`'mz'` ではない）|
| 積まれるイベント | `onDestroy`・`onSendToGrave` **だけ** |
| 積まれないイベント | `onRemove`・`onLeaveField` |
| 破壊耐性 | `applyDestructionProtectionV21` は zone が mz / sz / field のときだけ見るので通らない |

そこで `runSummonWindowResumeS03`（`engine/40`）の取り消しを、**カードがまだ手札にあるときだけ**
`MOVE` から `FX_TO_GRAVE`（zone `'hand'` ＋ `byDestroy`）に替えた。手札に戻す枝（S03-U277 キックバック）と
反転召喚の枝は**新しい枝より前**にあるので、そちらは何も変わらない（テストで順序を固定）。

カード側も 1 枚直した。《人造人間－サイコ・リターナー》は `WIKI-0A19E6117879` の当事者なのに、
共有ヘルパ `e8FromFieldToGrave`（`graveInfo.from` が `'mz'` か `'sz'`）で縛られていて裁定の場面で
発動できなかった（実測）。テキストは「このカードが**墓地へ送られた時**」でフィールドからとは書いていない。
専用の判定に替えた。**共有ヘルパ自体は変えていない。**

## 未対応の範囲

1. **解決中の召喚（`engine/1ZZY`）はまだ素の `MOVE` で、破壊も墓地送りも積まれない。**
   《血の代償》《デュアル・サモナー》の効果による通常召喚とデュアル再召喚がこれにあたる。
   これらはカードが**すでに場に居る**ので手札からの破壊には替えられず、別の形
   （場から取り除きながらフィールドでの破壊扱いにしない）が必要になる。5-a #1-j に残した。
   テストでは「まだ綿毛トークンが出ない」ことを**未対応として固定**している。

2. **破壊したプレイヤー（`byPlayer`）が `null` のままである。**
   `SUMMON_WINDOW_NEGATE_V42` は誰が無効にしたかを記録していないので、
   「**相手によって**破壊され墓地へ送られた時」を条件とする効果（《聖騎士ジャンヌ》②など）は
   まだ当たらない。この点についての当時裁定は**確認していない**。

3. **シンクロ召喚の無効（`WIKI-6745DCCBE047` 10/07/18・`WIKI-EFE5568A43B4` 10/05/18）は対象外。**
   エクストラデッキから出る召喚の窓はこの単位では触っていない。

4. 《アマゾネスの里》（`WIKI-EFB088FAC57A` の掲載ページ）は、カード側が**戦闘破壊だけ**の誘発として
   実装されている（`passive.onDamageStep` のみ）。テキストは「戦闘・**効果**で破壊され墓地へ送られた時」
   なので効果破壊の側が未実装で、この単位でも直していない（別単位）。
   そのためこのカード自身では裁定の場面を再現できず、同じ形の《人造人間－サイコ・リターナー》で測った。
