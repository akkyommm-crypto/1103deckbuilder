## 1. 当時裁定から組み立てたもの（推測していない）

- `WIKI-1D20AFD4E3D6`（10/08/31）変化した攻撃力・守備力は**元々の数値として扱う**
  → 「元々の数値を変える層」（`setBaseAtk` / `setBaseDef`、engine/00 の `curStat`）で持つ。
  数値はカードのゾーン限定の印（`u524ShadowStatS03`）に置くので、場を離れる・セットに戻ると消える。
- `WIKI-3B285A5D988E`（10/08/31）《収縮》《巨大化》は**変化した後の数値**の半分・倍になる
  → 層の順序（元々の数値 → SET → 増減 → 倍率）のままで満たせる。ただし《収縮》の実装が
  印刷された攻撃力（`dbOf(card).atk`）を読んでいたため、このカードでは 0 の半分になってしまっていた。
  「元々の攻撃力」を返す既存の取得元 `p3OriginalStatV3`（engine/12）に 1 行差し替えた
  （カードのテキストも「元々の攻撃力は半分」なので、これが本来の読み方）。2500 → 1250 を実測。
- `WIKI-86265C2E44AE`（09/06/12）生存後もダメージステップ終了後も変化した数値のまま
  → ターンやステップで消さない（《くず鉄のかかし》で攻撃を無効にして生存させ、2500 のままを実測）。
- `WIKI-05116421EE18`（09/08/30）2 体目の攻撃宣言ではその攻撃力に上書き
  → 攻撃宣言の度に上書き（2500 の後に攻撃力300 で宣言させ、相打ちになる＝300 になっている事を実測）。
- `WIKI-502486CEABE6`（10/06/18）/ `WIKI-99CF1034A52C`（10/09/06）攻守の変動はチェーンブロックを作る
  → 攻撃宣言時の**強制の誘発効果**（数値が同じでも発動する）。
- `WIKI-33529E04EA15` 対象を取らない → 攻撃対象になったこのカード自身を見るだけ。
- `WIKI-D56999420D78`（09/02/09）セットされる時もチェーンブロックを作る
  → 相手のエンドフェイズの強制の誘発効果。モンスターとしての状態（`asMonsterDbS03`）と数値の印を落とし、
  `setTurn` を記録して伏せカードに戻す。
- `WIKI-801C30BE612F` 破壊されて墓地へ送られた場合はセットされない → 誘発はモンスターゾーンに表側の時だけ。
- `WIKI-E1A1FA697B9E` / `WIKI-02A8DC802BDB` / `WIKI-2E645AE2C1C6`（09/08/30）セットできない状況では
  フィールドに残り続ける → `setBannedS03` を見て、セットできない時はセットしない。

## 2. 実経路で測ったこと

`tools/test_s03_u524_shadow_gardna.js`（18 PASS）。Replay 監査は 6 場面。

- 自分のメインフェイズでは発動できず、相手のメインフェイズに発動して機械族・地・星4の罠モンスターになる
  （攻守は ? = 0 から始まる。罠カードとしても扱われる）。
