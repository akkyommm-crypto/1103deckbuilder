## 4. 強制／任意の分類の確認（条件1）

### 4-1. カード単位の「強制 255」はエンジンの判定ではない

S03-U493 の監査は「スクリプトのどこかに `forced` があるか」で 255 枚を強制と数えていた。
エンジンが実際に使う判定は候補ごと・効果ごと（`engine/1ZB` の `triggerCandidateForcedS03`）である。
**イベントごとに測ると、255 枚のうち 8 枚は召喚系のどのイベントでも強制ではない**
（強制なのは `onDestroy` / `onEndPhase` / `onStandbyPhase` / `onSendToGrave` の別の効果）:
《エア・サーキュレーター》《カラクリ商人 壱七七》《コアキメイル・ルークロード》《ドラグニティ－アキュリス》
《フォーチュンレディ・ウインディー》《ボーンクラッシャー》《ワーム・ミリディス》《沈黙のサイコウィザード》。

**測り方で踏んだ誤り**: `triggerCandidateForcedS03` に ctx の無い作り物の候補を渡すと、v4 の effect 選択
（`v4SelectEffectForContext`）が条件を満たせず `null` を返し、強制の効果まで任意に見える。
その測り方では 28 枚と出たが、実経路（実際に召喚・反転召喚して `collectHandlers` が出した候補）で
照合すると《ワーム・ヤガン》は強制だった。**イベントごとの効果の `forced` を読み、実経路で照合する**のが
正しい測り方で、その数が 8 枚である（テスト E1 / E2 で固定）。

### 4-2. 当時裁定が「強制」と明言しているのに任意として登録しているカード

落としている (card, event) 組のうち、**該当句に「できる」が無い**（＝強制誘発と読める）ものが
50 組 / 37 枚あった。そのうち当時裁定が強制だと明言している **6 枚**を (B-1) で宣言した（§5-3）。
残り 31 枚 / 43 組は**未確定**として残した（§6）。

《ラヴァル・グレイター》《ラヴァル・ステライド》（`WIKI-D42D50F4CFCD` / `WIKI-2DCE27070FC3` 10/04/30
「手札０枚の時にシンクロ召喚した時でも…効果が発動し、チェーンブロック自体は作られます」）は、
v4 の effect がそのイベントに `forced:true` を宣言しているので宣言不要だった（当時裁定と一致）。

## 5. 直したこと（条件2・条件3）

### 5-1. 文言を効果ごと・イベントごとに読む（R9）

根拠: `WIKI-BC4886A97EED`（《魔導戦士 ブレイカー》、取得 2011-08-30）
「このカードが反転召喚・特殊召喚に成功した時、魔力カウンターを乗せる誘発効果は発動しますか？」
→「いいえ、発動しません。**「召喚」とは、「表側攻撃表示または表側守備表示での通常召喚」を指します。**」

S03-U493 は 1 枚のテキスト全体を 1 つの「召喚句」としてまとめていた。2 つ誤る。

- 正規表現の選択肢が「召喚」から並んでいるため、**「特殊召喚に成功した時」の中の「召喚に成功した時」に当たる**。
  実測: 《アルカナフォースEX－THE LIGHT RULER》（句は「特殊召喚に成功した時」だけ）が
  通常召喚・反転召喚のイベントでも種別に入っていた。
- 関係の無い効果の「場合」で 1 枚まるごとの判定が変わる。

いまは句の直前の召喚語を**長い語から**読み、N（通常召喚・アドバンス召喚・生け贄召喚）/
S（特殊召喚・融合召喚・儀式召喚・シンクロ召喚・エクシーズ召喚・S召喚）/ F（反転召喚）/ R（リバース）に
分けて、イベントに対応する種類の句だけを見る。

**テキスト層が時代混在であることの実測**（候補 518 件のテキスト）:

| 測ったもの | 件数 | 意味 |
|---|---|---|
| 「S召喚」 | 17 箇所 | 2011 当時は「シンクロ召喚」。S03-U493 はこれを「召喚」と読み、シンクロ召喚の句を**通常召喚のイベントに結び付けていた**（8 枚）|
| 「生け贄召喚」 | 6 箇所 | 2010-03 に「アドバンス召喚」へ変わった旧用語 |
| 「アドバンス召喚」 | 32 箇所 | 新用語。**同じ層に旧新が共存している** |

**この訂正だけで判定が変わる現役カードは無い**（該当する 9 枚はいずれも別の理由で落とさない）。
読み方の正しさを先に揃えたもので、挙動の差は次の 5-2 / 5-3 の分である。

### 5-2. `flipSummonReverse` 種別を無効にした（R8）

根拠は §2 の 3 件。S03-U493 はこの種別を**当時の根拠を確認せずに**有効にしていた。
実測で 7 枚がこの種別で落ちていた: 《スノーマンイーター》《ペンギン・ナイトメア》《不死王リッチー》
《渋い忍者》《裏ガエル》《電池メン－単四型》（onFlip）《魔轟神獣ペガラサス》。

あわせて測ると、**測った反転召喚の経路では刻みが動かない**（`FX_SET_STATE` 1 回で終わり、
onFlip の stamp と現在値が等しい）ので、この経路ではこの 7 枚は落ちていない。
**他に刻みが動く反転召喚の経路があるかは確認していない。**
規則としては誤っていたので、根拠を付けて外した（テスト C1 / C3 / C4）。

これで「効果で表側にされたリバース効果」も判定しないため、S03-U493 の未対応 #2 は**規則として解消**した。
