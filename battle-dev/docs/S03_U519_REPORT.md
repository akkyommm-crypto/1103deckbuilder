## 1. 当時裁定から組み立てたもの（推測していない）

### パワー・フレーム
- `WIKI-518D4C8C4B50`（10/02/21）「このカードは攻撃したモンスターも対象に取りますか？」
  →「いいえ、対象に取るのは攻撃対象になったモンスター1体だけ」→ 対象は攻撃対象モンスターだけ（発動時に宣言）。
- `WIKI-3AA3F72AEC8B`（10/02/21）《突進》をチェーンして攻撃対象の攻撃力が攻撃モンスターを上回った場合でも
  「攻撃力が上がる効果は適用され…差は600になりますので…1600+600=2200になります」
  → 上げる数値は**解決時**の両者の攻撃力の差（絶対値）。テストでは 300→1000 にして差 1500・合計 2500 を測った。
- `WIKI-2916A8C2E7B4`（10/03/24）発動にチェーンした《サイクロン》で破壊されても攻撃は無効になる
  → 解決では先に攻撃を無効にし、装備はカードが魔法＆罠ゾーンに残っている時だけ行う。
  テストではカードが墓地に行き、モンスターが残り、戦闘ダメージも発生しない事を測った。
- 発動できるタイミングは `passive.onAttackDeclare`（《次元幽閉》《聖なるバリア －ミラーフォース－》と同じ形）。
  罠の自己装備は `API.equipSpell`（`FX_EQUIP`）が魔法＆罠ゾーンのカードなら種別を問わないのでそのまま使える。
  上昇値は装備の継続効果（`scope:'equippedMonster'`）で、数値はゾーン限定の刻印に持つ。

### フォーメーション・ユニオン
- `WIKI-B49FAB74603A`（09/03/05）《スキルドレイン》でユニオンの効果が無効でも装備させられる。
- `WIKI-D657D4542632`（09/03/05）《エンジェルＯ７》等でユニオンの効果を発動できない状態でも装備させられる。
  → これは**罠カードの効果**なので、ユニオンモンスター自身の効果の発動可否や「1ターンに1度」とは無関係
  （`unionTurnS03` を消費しない）。テストではスキルドレイン適用中に装備できる事を測った。
- `WIKI-8294B5F99F4B`（09/01/20）装備した同じターンに解除して特殊召喚でき、再度装備もできる
  → 回数制限を付けない。テストでは同じターンに装備 →（別の1枚で）解除して表側攻撃表示で特殊召喚を測った。
- 「装備可能なモンスター」は各ユニオンが宣言している host 規則そのもの。S03-U313 の `declareUnionS03` が
  受け取っていた規則を `UNION_HOST_S03` に保持し、`unionCanEquipS03(union, host)` で引けるようにした
  （規則自体は変えていない。16 枚が登録されている）。
- 未確定（RULING_UNRESOLVED）: 当時テキストの「選択」が対象を取るかを答える当時の裁定が無い。
  ここでは**発動時に●のどちらを行うかだけ宣言**し、カードは解決時に選ぶ形にした。
  現在のテキストは対象を取る書き方だが、当時の文言から対象を取ると断定できないため、そのまま記録する。

## 3. 未対応・後続課題

1. **手札の速攻魔法がチェーン応答の候補に出ない**（`canActivateFromZone` がスクリプトの `activateFrom` 宣言を
   要求するため）。セットした速攻魔法は出るので、この単位のテストはセットで測った。S03-U517 で
   《サモンチェーン》に `activateFrom:['hand','sz']` を足したのと同じ修正が、他の速攻魔法にも必要。
   engine 側で「速攻魔法は手札から発動できる」を既定にする案があるが、既存の多くのカードの候補一覧が変わるため
   独立した単位で測る。
2. 《一角獣の使い魔》（同じ「攻撃対象に選択された時」族）は、効果で除外した後に
   「その時の攻撃モンスターは攻撃しなければならない」を満たす必要がある。
   当時裁定（`WIKI-8C8BCD32C99D` 10/05/25 誘発効果 / `WIKI-82BEFEF1789E` 10/04/19 除外はコスト /
   `WIKI-BC76C9E80F7C` 10/04/19 裏側になったら除外されない / `WIKI-40FD0E78ED6D` 10/04/21 戻る時にチェーンを作らない /
   `WIKI-EF5EB50DD8DF` 10/05/24）は揃っているが、攻撃対象が場を離れた後の巻き戻しで攻撃を強制する仕組みが無い。
3. S03-U517/U518 から持ち越し: `TOKEN_CREATE` が召喚制限を見ない / 複数体を出す効果の発動可否 / LP コストの読み方。
