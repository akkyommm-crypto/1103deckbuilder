# S03-U501 報告：召喚を無効にされたモンスターの行き先を実測し、当時裁定と照合した（挙動の変更なし）

S03-U498〜U500 で召喚無効の窓を入れたとき、取り消しの形は
「召喚は成立していないので、手札から出した分は `MOVE` で墓地へ送る」と決めた。
その判断の根拠は `WIKI-2CF23AA42E79`（窓そのものの裁定）だけで、**行き先についての裁定は引いていなかった**。
この単位では裁定 DB を**召喚無効の側から**引き直し、**回答日のある裁定を 4 件**見つけた。

本単位は **挙動を変えていない**。変えたのは文書とテストだけである。

## 3. 食い違い（未対応として記録）

1. **手札から出した召喚を無効にすると、そのモンスターのイベントが 1 つも積まれない**（5-a #1-j）。
   当時裁定（**回答日 2010-05-17**）では「破壊され墓地へ送られた時」の効果が発動できる。
   影響しうるのは **通常召喚できるモンスター 176 枚**（自分の破壊／墓地送りを見る `passive` を持つもの。
   全件数えた。`onDestroy` 111 件・`onSendToGrave` 180 件の passive のうち、EX でないモンスター）。
   **これは公開済みの経路（UI 起点の通常召喚・特殊召喚手順）の食い違いである。**
2. 解決中の通常召喚では逆に**場からの離脱だけ**が積まれる（5-a #1-i。S03-U500 で記録した分）。
   当時は「フィールドに出なかった」扱いなので、これは出てはいけない方である。

## 4. 合っているところ（固定した）

- **通常召喚の権利は戻らない**（`WIKI-2C8BE04F46E9` / `WIKI-2ABC596B02C7`、回答日 2007-03-26）。
  実測: UI 起点の通常召喚を無効にされた後も `normalSummonUsed` は真のまま。
  効果による召喚（《血の代償》）はもともと権利を使わないので、無効にされても偽のまま。
- **反転召喚を無効にするとリバース効果は出ない**（`WIKI-43E80F61C77D`、回答日なし）。
  実測: 《メデューサ・ワーム》の反転召喚を《神の宣告》で無効にすると、相手の《ワイト》は破壊されない。

## 5. 直すときに要る形（次の単位への設計。設計書 (E)）

「**フィールドに出ないまま破壊されて墓地へ送られた**」という取り除き方が engine に無い。
いまあるのは `MOVE`（何も起きない）と `FX_TO_GRAVE byDestroy`（フィールドでの破壊として全部起きる）の
2 つだけで、その中間が無い。要るのは
`onDestroy` / `onSendToGrave` は積み、`onLeaveField` は積まず、「フィールドで破壊された」ことを条件とする
判定（`graveInfo.from==='mz'`、「Sin」の蘇生条件、《デストラクション・ジャマー》）には当たらない形である。
`v9DetectLeaveField`（`engine/18`）は**盤面の差分**で離脱を検出するので、そこに除外を入れることになる。
**公開済みのルール処理**なので、測ってから別単位で行う。
