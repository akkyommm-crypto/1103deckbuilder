## 修正

《血の代償》から《ダンディライオン》を通常召喚し、《神の宣告》で無効にすると、
素の MOVE で墓地へ移るため綿毛トークンが出なかった。
同じ経路の《人造人間－サイコ・リターナー》も蘇生効果が発動しなかった。
U509 の手札上の召喚無効と同じ裁定に従い、この残りの経路を修正した。

- `engine/1ZZY`: 非デュアル再召喚の取り除きを `FX_TO_GRAVE byDestroy:true` に変更。
- `engine/00`: U502 の uid 申告と一致する対象だけ、物理的な mz 格納とルール上の由来を分離。
  `from:'summon'` は新ゾーンではなく、未成立の召喚の由来を表す JSON 値。
  onDestroy / onSendToGrave を発生させ、onLeaveField / 場の onRemove は発生させない。
  場の破壊耐性、装備身代わり、場から離れる場合の置換・付帯情報も適用しない。
- `engine/07`: マクロコスモスで除外される場合も、除外元を mz と誤記録しない。
  墓地行き置換と除外イベント自体は維持。
- デュアル再召喚・反転召喚・キックバック、所有者への行先振り分けは従来どおり。
  カード名によるエンジン分岐なし、カード側変更なし、保存形式のバージョン変更なし。

根拠: U509 の収録裁定 WIKI-0A19E6117879 (2010-06-05)、WIKI-D70393946D93
(2010-09-16)、WIKI-643A78AB3480 (2008-03-19)、WIKI-9E991E9B14E9 (2010-04-21)。
「破壊され墓地へ送られる」と「フィールド上で破壊されたわけではない」を両方満たす。
