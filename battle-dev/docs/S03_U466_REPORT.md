# S03-U466 - スペシャル・デュアル・サモン

基点: `codex/battle-u465` のU465コミット。既存のデュアル状態と直列化可能なスケジューラを接続し、旧 `ENGINE_GAP` を解消した。

## 実装

- 自分フィールドの表側デュアルを対象にする速攻魔法の実発動。
- 通常召喚権を消費せず、対象を再度召喚した状態にする。
- 発動ターンのエンドフェイズに、対象の同じフィールド滞在だけを持ち主の手札へ戻す。
- 対象が一度場を離れて再召喚された場合は、古い予約を適用しない。

## 検証

- Negative control（U465ビルド + U466テスト）: **4 FAIL**（発動・状態付与・予約・帰還が未実装）。
- 修正後: U466 **8 PASS / 0 FAIL**。
- 実経路: 手札からの速攻魔法発動、対象選択、チェーン解決、エンドフェイズprocessor、予約のJSON検査、場を離れて再召喚するnegative control、Replay audit。
- 回帰対象: System v7 scheduler、U119/U164/U465のデュアル。
