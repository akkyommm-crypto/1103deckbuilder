## S03-U472 追記（複数のカードを対象にする5枚 × メタルシルバー・アーマー、2026-10-25）
- 出典: `wiki-rulings.js` の **WIKI-32A7C5F81B06**（`answerDate` 2009-06-18, `backupDate` 2011-05-28, 元ページ 《メタルシルバー・アーマー》）。
  - 質問: 「自分がこのカードと装備モンスターをコントロールしているとき、相手は《ゴッドバードアタック》など複数のカードを対象にするカードでモンスターを対象に発動することができますか？」
  - 回答: 「複数のカードを対象にする効果の場合、発動を制限することはできません。よって発動することができます。（09/06/18）」
  - 対照（同ページ・同日）: **WIKI-6B27D6D86996**「相手は墓地のモンスター１体を対象にする効果を発動できますか？ → いいえ、発動できません。」（単体対象は制限される。U468 で実装済み）。
- **採用した解釈（裁定の一般的な回答文に基づく Codex の採用解釈。ユーザー確認済み 2026-10-25）**: メタルシルバー・アーマーの対象制限は、**複数のカードを対象にする効果には掛からない**。その効果は装備モンスター以外のモンスターも対象に選べる。アーカイブの回答は「発動を制限できない」までしか述べておらず、「保護されたカードを対象の1枚に選べるか」はこの解釈で補っている（アーカイブが直接述べた事実ではない）。
- 実装: 効果の対象枚数をスクリプトの宣言 `targetCount` で示し（`engine/1ZZR` が `effectInfo.targetCount` / `targetsMultiple` に出す）、**アーマーの `immuneToTarget` / `immuneToTargetOffField` だけ**が `targetCount >= 2` の時に制限を掛けない。選択の min/max や選択 UI の形からは推測しない。コストで選ぶカードは数えない。宣言があるのは 貪欲な壺(5) / 諸刃の活人剣術(2) / 毒蛇の供物(3) / TGX3－DX2(3) / ゴッドバードアタック(2) の5枚だけ。強制脱出装置など単体対象は宣言なしで制限されたまま。他の対象耐性（ホルスのしもべ・氷結界の御庭番・ヴァイロン・セグメント・闇の侯爵ベリアル・ターボ・ウォリアー・ヴァイロン・エプシロン・機皇城・ジュラック・タイタン・安全地帯・ガイアドレイク・エレキリギリス・オベリスクの巨神兵）は変更なし。詳細と検証は `docs/S03_U472_REPORT.md`。
- **この回答が決めていない点（残り）**:
  1. 質問は「フィールドのモンスター」を対象にする複数対象（ゴッドバードアタック）を問うている。回答文自体は「複数のカードを対象にする効果」と述べるだけで、対象の場所（フィールド／墓地）を限っていない。**墓地を対象にする複数対象**（貪欲な壺 / 諸刃の活人剣術 / TGX3－DX2）にも同じ文を当てているのは、この一般的な回答文に基づく Codex の採用解釈で、墓地のケース専用の回答があるわけではない（例が《ゴッドバードアタック》であることは、墓地を除く理由にしない。ユーザー確認済み、現行の実装を維持。単体の墓地対象 WIKI-6B27D6D86996 は制限される、との対照とは矛盾しない）。
  2. 「複数のカードを対象にする」の境界。自分のモンスター1体＋相手のカード2枚（毒蛇の供物）は①の文言で3つの対象なので複数とした。「最大N体まで」のような可変数の対象を取る効果は、現時点でこの宣言を使うカードが無く未検討。
  3. 複数の対象のうち一部だけが他の耐性で保護されている場合（例: ホルスの黒炎竜を含む場）は、**他の耐性は変えない**方針で、保護されたカードだけが候補から外れる（アーマーの例外はアーマー由来の制限にしか効かない）。
