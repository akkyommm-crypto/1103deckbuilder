1103 ADS System v3.5.1 CHANGELOG
====================================

1. Android / Acode 実機スモークの経路修正
- v3.5.0ではDEVELOPERモードで盤面セット後、そのままカードをタップすると旧MANUAL経路へ流れていた。
- 新ADS/DUELエンジンを検証するテストなのに別経路を操作していたため、複数シナリオが一斉にNGになり得た。
- v3.5.1では実機テスト開始時だけPLAY_MODEをDUELへ自動切替し、PASS/NG記録または中止時に元モードへ戻す。
- テスト中は通常メニューから「📱 実機テスト結果へ」へ戻れる。
- 盤面セット直後に初動LEGAL ACTIONを自動確認し、READY / SETUP NGをログへ表示。

2. 《天空の宝札》後の合法操作修正
- 特殊召喚禁止中の《死者蘇生》は「発動して解決時に失敗」ではなく、そもそも発動できない。
- 特殊召喚そのものを目的とするスクリプトへ blocksIfNoSpecialSummon を追加。
- DUELの手札魔法・伏せ魔法罠についても strictScriptLegalityV2 をボタン表示前に通すよう修正。
- 「DUEL = 合法操作だけ表示」の原則を魔法・罠にも徹底。

3. 《六武衆の荒行》End Phase破壊の実バグ修正
- v340ScheduleEndDestroy() は flagKey:'v340EndDestroyTurn' を予約へ渡していたが、RESERVE_ADDがflagKeyを状態へ保存していなかった。
- そのため特殊召喚とEnd破壊予約は成功しても、End Phaseの破壊条件が成立しなかった。
- RESERVE_ADDでflagKeyを永続化するよう修正。
- 実行回帰テストで「キザン対象→ザンジSS→Endでキザンだけ破壊」を確認。

4. 実行回帰テスト強化
- v3.5.1専用の実機経路テストを追加。
- 天空の宝札: noSpecialSummon / noBattlePhase / 死者蘇生発動不可 / 2ドロー。
- 緑光の宣告者: サイクロンへの応答候補、2枚コスト、発動無効・破壊。
- 紫光の宣告者: 強制脱出装置への応答候補、2枚コスト、対象モンスター残存。
- 六武衆の荒行: ザンジSS、End予約、対象キザンのみ破壊。
- E・HERO ボルテック: 攻撃開始合法、damage-after誘発、除外エアーマンSS。

- systemVersion: 3.5.1
- 明示カードスクリプト: 240 unique
- Acode内蔵カードDB: 4,996 cards
