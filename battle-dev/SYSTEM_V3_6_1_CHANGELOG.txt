1103 ADS System v3.6.1 CHANGELOG
====================================

1. 《奈落の落とし穴》の同時召喚処理を修正
- 《レスキューラビット》の効果で同時に特殊召喚された2体を、1つのonSpecialSummonイベントのcards/uidsとして扱う既存基盤を奈落が正しく参照するよう修正。
- 奈落は対象を取らないため、1体を選ぶUIを廃止。
- 発動のきっかけになった召喚バッチだけを記憶し、解決時にその中の表側・攻撃力1500以上を全て処理。
- 以前から場にいた攻撃力1500以上のモンスターは巻き込まない。
- 解決時に《収縮》等で攻撃力1500未満になった個体は破壊・除外しない。

2. 「破壊して除外」の共通プリミティブ
- FX_DESTROY_BANISH を追加。
- API.destroyAndBanish() を追加。
- 単純な除外と区別し、onDestroy / onRemove の誘発情報を保持。

3. 回帰テスト
- tools/test_bottomless_batch_v361.js を追加。
- ラビット2体SSが1つの同時特殊召喚イベントになることを確認。
- セイバーザウルス2体が奈落で両方除外されることを確認。
- 既存モンスターを巻き込まないことを確認。
- 解決時1500未満の個体が処理されないことを確認。
- Android/Acode実機スモークに「レスキューラビット：同時2体SS→奈落」を追加（10シナリオ）。

4. 維持
- 明示カードスクリプト: 240 unique
- カードDB: 4,996枚
- v3.6.0 UI / v3.5.1実機経路 / 召喚タイミング / X素材 / ヴェーラー等の既存回帰を維持。
